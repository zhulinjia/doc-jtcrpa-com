# AI 模型与密钥配置

**先说结论：登录后默认就能用，这一步可以跳过。**

只在下面两种情况才需要配：

- 你想用**自己从 AI 厂商申请来的密钥**（比如已经买了 DeepSeek、OpenAI 的额度）；
- 你想接**别家的服务**——只要它兼容 OpenAI 的接口协议就行。

## 一、默认通道：不用配

登录官网账号后，编译走的是 **「官网中转 · 计费」** 这条通道，用的模型显示为 **「官方 AI API」**。

**它会消耗你账号里的额度**，不用自己申请任何密钥。剩余额度在「**设置菜单**」的账号卡片里看——
就在菜单最上面，写着「充值额度」和「赠送额度」两笔。

**想切模型，去对话页切**——在**对话区底部的输入框那一行**有个模型下拉，
里面能选通道和模型。**不是在配置页里选。**

## 二、进配置页

**点击侧边栏最下方的「设置菜单」-> 点击「AI KEY 配置」**。
配置页会在浏览器的新标签页里打开。

页面标题是「**AI 模型服务中心**」，下面写着
「**直接在下方填写对应厂商的 API Key，所有密钥均保存在您本地浏览器中**」。

## 三、四个厂商，四个输入框

页面上是**四张厂商卡片**，从上到下：

| 卡片 | 卡片上写着的模型 |
| :--- | :--- |
| **DeepSeek** | DeepSeek Chat |
| **OpenAI** | GPT-4o、GPT-4o mini |
| **Anthropic Claude** | Claude Opus 5、Claude Sonnet 5、Claude Haiku 4.5 |
| **Google Gemini** | Gemini 3.7 Flash、Gemini 3.1 Pro (Preview)、Gemini Flash (Latest) |

**每张卡片上有两样东西：**

- 一个**输入框**（提示语是「请输入 API Key ...」）——把你在那家申请到的密钥**粘贴进去**；
- 一个「**获取 Key**」的链接——点它直接跳到那家的网站去申请。

**只填你要用的那一家就行**，别的一个都不用管。哪家的密钥都没申请过，就别配这一步。

::: tip 不提供厂商选择的地方
这一页**只列这四家**。想用别家的服务，见下面第五节的「自定义 AI 提供商」。
:::

## 四、填完就生效，没有保存按钮

**边填边存。** 页脚写着「**密钥仅保存在您本地浏览器中，修改即时生效**」——
别在页面上找保存键，没有。

想核对粘贴对不对，把鼠标停在输入框那儿的「**显示**」/「**隐藏**」上，
点一下就能看见明文。

::: warning 这一页没有「测试连接」
**配得对不对，只能发一条采集需求试出来。** 别在这一页上找测试按钮，找不到。

（「测试连接」只有**飞书多维表格**那个配置页里有，是另一回事。）
:::

## 五、自定义 AI 提供商

兼容 OpenAI 接口协议的第三方服务，可以自己加进来。

**页面上有一个「自定义 AI 提供商」的区块，点「添加」**，弹出「**添加自定义 AI 提供商**」的窗口。
窗口里写着「按 OpenAI 兼容协议填写，名称必填；保存后可在下方列表继续编辑」，四个输入框：

| 输入框 | 填什么 |
| :--- | :--- |
| **提供商名称** | 你给它起的名字。**必填**，不填，「添加」按钮点不动 |
| **API 地址** | 对方给的接口地址，形如以 /v1 结尾的那种 |
| **模型名** | 对方文档里写的模型名字 |
| **API Key** | 对方给你的密钥 |

填完点「**添加**」，一个都不想要了点「**取消**」。

已经加过的会列在下面；一个都没加时，那里写着
「**暂无自定义提供商，点击「添加」接入兼容 OpenAI 协议的第三方服务**」。

::: tip 建成之后，只有密钥还能改
**名称、地址、模型名填错了，建成之后就改不了了**——想改就把它删掉重新加一个。

（弹窗里那句"保存后可在下方列表继续编辑"，实际只有 API Key 那一栏能编辑。
这里是界面上的小毛病，以实际能改的为准。）
:::

## 六、配错了会看到什么

编译时出错，对话里可能出现这三种卡片之**一**：

| 卡片标题 | 按钮 | 什么时候出现 |
| :--- | :--- | :--- |
| **当前 AI 模型还没有配置 API Key** | 去配置 | 选了自己密钥的模型，但密钥没填 |
| **需要登录官网账号** | 去登录 | 用了官网通道，但没登录 |
| **额度不足** | 去充值 | 官网通道的额度用完了 |

**照卡片上的按钮走就行。**

::: warning 不是所有出错都会给你一张卡片
**服务繁忙、超时这类临时故障，可能只有一句报错，没有卡片**——那不是你配置的问题，
等一会儿再发一次通常就好。
:::

::: warning 填了自己的密钥，却看到「需要登录官网账号」？
**多半是密钥本身不对或者已经失效了。**（这类错误在两边长得一样，界面分不出来。）

去密钥所属那家厂商的网站，看看密钥是不是被删了、额度是不是到期了，
不行就重新生成一个，再粘回来一次。**不用去登录官网账号。**
:::
