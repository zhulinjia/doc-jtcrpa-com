# AI 模型与密钥配置

首次使用建议先登录官网账号，使用默认的「**官方 AI API**」。账号有可用额度时，无需自己申请密钥，可以直接开始[第一个任务](/guide/first-task)。

只有准备使用自己购买的 AI 服务时，再看下面的设置。

## 使用自己的密钥

1. 打开「**设置菜单 → AI KEY 配置**」，进入「**AI 模型服务中心**」。
2. 找到对应厂商，把该厂商提供的 **API Key** 粘贴进去。只填你要使用的那一家。
3. 修改会自动保存。需要核对时，用「**显示**」与「**隐藏**」查看。
4. 回到「**AI 编译生成**」，在对话输入区底部的模型下拉中选择对应服务和模型，发送一条小需求试用。

密钥是服务商给你的访问凭据，不是网站登录密码。不要发到聊天需求、截图或公开工作流中。这一页没有测试连接按钮，实际发一条需求才能检查所选服务能否使用。

## 接入其他服务

如果对方提供兼容 OpenAI 的服务，找到「**自定义 AI 提供商 → 添加**」，按对方说明填写提供商名称、API 地址、模型名和 API Key，再点击「添加」。

添加后回到对话区选择它。名称、地址或模型名填错时，当前界面需要删除该项再重新添加；已有项可以直接修改密钥。没有接收方提供的资料时，无需尝试填写。

## 有额度，为什么还是用不了

官网账号的额度与其他 AI 服务商的额度分别计算。先检查对话区实际选择了哪个模型，再处理对应服务的登录、密钥、余额和网络问题。

| 看到的提示 | 可以做什么 |
| :--- | :--- |
| 当前 AI 模型还没有配置 API Key | 点「去配置」，或切回有可用额度的默认通道 |
| 需要登录官网账号 | 使用官网通道时点「去登录」；自带密钥时也检查所选服务与密钥状态 |
| 额度不足 | 检查当前服务的额度，按需要充值或更换已配置的服务 |
| 服务繁忙或超时 | 保存需求，稍后重试；持续出现时记录完整提示反馈 |

不要通过反复生成同一任务来测试大型需求。先用练习书店的一页数据确认连接，成功后再处理自己的网页。
