# 邮箱、电话与图片提取

内置了三个轻量独立的即时提取工具，用于从**当前打开的网页**中秒级提取关键资源：

| 工具名称     | 提取对象                         | 典型应用场景                          |
| :----------- | :------------------------------- | :------------------------------------ |
| **邮箱提取** | 页面内出现的所有电子邮箱地址     | 外贸客户开发、公关合作联系方式收集    |
| **电话提取** | 页面内出现的所有手机号与固定电话 | 商务拜访拓客、客服热线整理            |
| **图片提取** | 页面实时嗅探到的所有图片资源     | 电商主图/详情图批量下载、设计素材收集 |

::: tip 即开即用，无需编译工作流
这三个工具**不依赖 AI 分析，不需要生成工作流，也不消耗任何额度**。打开网页后点开工具即可秒出结果，随时支持一键批量导出。
:::

::: warning 使用前提：必须是常规互联网网页
浏览器内部设置页（如 `chrome://`）、官方应用商店页以及本地 HTML 文件（`file:///`）受浏览器安全策略限制，**无法执行提取**。在普通网站（如电商、资讯、企业官网）上均可正常使用。
:::

## 一、通用交互与去重规则

### 1. 入口位置

点击侧边栏左侧功能导航最下方的三个独立图标（鼠标悬停会浮现「邮箱提取」「电话提取」「图片提取」）。

页面顶部卡片会显示**当前正在捕获的网页信息**（站点图标、标题、URL）。若显示「_未检测到可提取的网页_」，请先将浏览器切到目标网页。

### 2. 自动提取与结果去重

- **切换即自动提取**：进入「邮箱提取」或「电话提取」面板时，系统会**自动对当前页面执行首轮提取**，无需先找启动按钮。
- **追加累加机制**：若你在网页内进行了操作并再次点击「提取」，新提取的结果会**自动与旧结果合并并自动剔除重复项**。
- **清空历史**：若需要清空当前提取列表重新开始，点击右上角「**清空**」按钮即可彻底重置。

### 3. 状态异常警示条

若页面需要刷新或属于不支持的网页，面板顶部会弹出虚线提示条：

- **需要刷新当前网页**：扩展刚安装或刚升级，**按 F5 刷新当前网页即可恢复使用**。
- **当前页面不支持操作**：当前停留在了浏览器受限页面，切到正常网页即可。

## 二、邮箱提取

1. 切换至「**邮箱提取**」，面板会自动扫描页面文本及 HTML 隐藏链接并呈现提取结果。
2. 若页面内容产生变动，可随时点击「**提取当前页面邮箱**」重新扫描。
3. 点击顶部的「**下载全部**」，结果将一键导出为纯文本文件（`.txt`，每行一个邮箱），文件名自动附带日期时间（如 `邮箱提取-20261015-1430.txt`）。

### 为什么需要选择「国家/地区」？

不同国家的本地电话号码长度与分段格式差异极大。提取器内置了 14 个常用国家/地区选项（默认：中国）：

| 号码书写形态                                              | 是否受下拉框影响      | 提取规则说明                                                         |
| :-------------------------------------------------------- | :-------------------- | :------------------------------------------------------------------- |
| **带国际区号**（如 `+1 415...`、`+86 138...`）            | ❌ **不受影响**       | 无论下拉框选哪个国家，系统均能精准通用识别。                         |
| **本地无区号号码**（如 `010-88888888`、`(415) 555-0100`） | ⚠️ **强依赖下拉选项** | **必须先将下拉框选为对应国家**，正则引擎才能正确匹配其本地号段规范。 |

> **实操技巧**：抓取国内平台保持「中国」即可；若在跨境电商或海外官网抓取电话，**务必先将下拉框切换为对应国家（如美国、英国、日本等）再点击提取**。

## 四、图片提取

图片提取采用**实时网络监听与 DOM 嗅探机制**，专门应对大量采用“懒加载”技术的现代网页。

<!-- TODO: [截图] 图片提取瀑布流展示卡片与悬浮下载按钮 -->

### 1. 正确的捕获姿势：慢慢向下滚动

进入「图片提取」面板后，**无需点击任何开始按钮**。

- 打开目标网页，**使用鼠标滚轮匀速向下滚动网页**。
- 随着页面向下滚动，新曝光的图片会被扩展瞬间捕获，面板顶部的「**嗅探到 N 张图片**」读数会实时累加跳动。
- **按文件体积降序排列**：列表默认将大图排在最前、小图标缩略图排在末尾，天然帮你过滤网页杂质。

::: tip 提示「未嗅探到图片」怎么办？
若打开面板发现列表为空，通常是因为网页在打开侧栏前就已经加载完毕，图片请求未被扩展捕获。**只需按 F5 刷新一次当前网页，重新向下滚动即可全量抓取**。
:::

### 2. 单张快速下载

鼠标悬停在任意图片卡片上，右上角会浮现**下载图标**。点击即可单张保存，文件名会自动附带数字序号前缀（如 `001-image.png`），避免重名覆盖。

### 3. 全部批量打包下载

点击面板顶部的「**全部下载**」，弹出保存设置弹窗：

| 设置项         | 填写规范与说明                                                                                                                                                                                                                                   |
| :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **保存文件夹** | 支持存入浏览器下载根目录的指定子文件夹下（例如输入：`素材/商品图A`）。<br>**⚠️ 切勿填写 `C:\Users\...` 这类绝对系统路径，必须填写相对子目录路径**。留空则直接保存在默认下载目录根下。                                                            |
| **冲突处理**   | 遇到本地已有同名文件时的策略（三选一）：<br>• **冲突时自动重命名（推荐默认）**：自动追加后缀序号，保证所有图片完整留存。<br>• **覆盖已有文件**：直接以新下载的文件替换旧文件。<br>• **已存在或进行中则跳过**：检测到已有同名文件则放弃该张下载。 |

## 五、账户与费用说明

- **无需登录账号**：无需注册或登录官方账户即可直接使用。
- **完全免费**：非会员与会员功能体验完全一致，**无条数额度限制，不计入套餐消耗**。
