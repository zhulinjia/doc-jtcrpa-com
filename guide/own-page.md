# 换成自己的网页

已经在练习书店拿到表格？现在打开工作中真正想整理的网页，先处理两三条，看看结果是否符合需要。

## 1. 打开能看见内容的页面

需要登录的网站，先由你自己登录。展开想看的列表或切到对应栏目，确认眼睛能看到目标内容。

在这张网页上打开扩展。浏览器设置页、应用商店等页面可能无法操作；遇到提示时看[页面不支持操作 / 需要刷新](/troubleshooting/page-not-supported)。图片、扫描件等也不能直接当作普通网页列表理解，应先用少量内容试验支持范围。

## 2. 说你想得到什么

进入「**AI 编译生成**」，可以直接说：

> 帮我整理这一页的商品名称和价格，先做前 3 条。

把“商品名称和价格”换成你真正需要的内容即可。AI 需要你选择列表或补充信息时，再按自己的目标回答。

换到另一个网站开始新任务，可以点击对话上方的「**新对话**」，再发送需求。想调整已有任务，则从「主工作台」的「**修改**」进入。

## 3. 运行并和网页对照

等工作流卡片出现后，回到约定的起始页面，在「主工作台」点击「**手动启动**」。在「数据存储」打开「**预览**」，逐行核对这几条内容，见[检查采集结果是否正确](/data/check-results)。

发现少了一列，可以从原任务的「修改」里接着说：“再帮我加上店铺名称。”内容不对，就说自己看到的差别。

## 4. 再增加范围

少量结果符合需要后，再说“把前两页也整理进去”等要求，重新运行并核对。不同网站的页面结构可能不同；为一个网站生成的任务，换到其他网站后需要重新检查或生成对应任务。

## 试着自己说一次

选一张你常用的网页，自己决定要哪些内容，先整理 3 条。不必照抄完整句式。完成后能对照网页说明每一列来自哪里，就可以继续扩大范围。
