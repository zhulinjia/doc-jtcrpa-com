# 编译期间会发生什么

发完需求后，AI 在后台具体在做什么？什么情况下会弹出卡片向你提问？了解这些，能帮助你更从容地掌握等待状态。

## 一、AI 在后台处理的三件事

当你点击发送后，系统通常会在 **15 ~ 40 秒** 内依次执行：

1. **解析网页结构** —— 分析当前标签页内的 DOM 层级、数据列表容器及按钮位置。
2. **试采抽样数据** —— 尝试执行一次抓取逻辑，验证能否真实获取你指定的字段。
3. **生成工作流并保存** —— 对话区显示「正在保存工作流…」，生成完毕后自动同步至「主工作台」。

整个编译过程全部自动进行。**期间页面会自动滚动、高亮选择或模拟点击，均属正常表现**。  
**⚠️ 在此期间，请勿手动点击、滑动或关闭该目标网页。**

## 二、什么时候会暂停并向你提问

只有当页面结构存在多种可能性、AI 无法单方面决策时，它才会在对话流中插入**交互卡片**。卡片顶部是具体问题，下方配有候选按钮。

回答方式有两种：

- **点击卡片上的候选答案**（推荐，最快捷）。
- **在卡片底部的输入框中手写回答**（提示语为「以上都不合适？直接输入你的答复」），写完后点发送。

完成答复后，卡片会自动折叠收起，并显示「已答复：你的选择」。

常见提问场景如下：

| 触发场景                 | 典型提问示例                                             | 你需要做的操作                         |
| :----------------------- | :------------------------------------------------------- | :------------------------------------- |
| **页面存在多个相似列表** | “页面上识别到左侧推荐列表与右侧主列表，请问采集哪一个？” | 点击确认你要的目标区域                 |
| **工作流名称重复**       | “检测到你已有名为‘商品采集’的工作流，是否覆盖或引用？”   | 选择具体要引用的任务卡片               |
| **需要先决页面状态**     | “当前数据需要登录后可见，或需要切换至指定标签栏”         | 切换到网页中完成操作后，点击「已就绪」 |
| **页面弹窗阻挡**         | “检测到营销弹窗或遮罩层遮挡了翻页按钮”                   | 在网页上手动关掉弹窗，随后确认继续     |

::: tip 自动出现的「清洗预览」卡片
如果你在需求中提到了数据清洗要求（如“去货币符号”或“只要销量大于 100”），对话区会弹出一张「**清洗预览**」卡片，以「原始数据 → 处理后」的对照形式展示清洗效果。

**该卡片仅供核对，上面没有按钮，看完即可，无需操作。** 底部标注的“运行期那遍才是权威”，意味着预览仅为抽样验证，正式运行任务时提取的全量数据才是最终结果。
:::

::: tip 卡住时支持直接放弃
如果不确定如何选择，可以直接在对话框中输入“先不弄了”或“换个思路”，AI 会退出当前编译轮次。
:::

## 三、等待超时或无响应排查

正常编译耗时一般在 1 分钟以内。如果超过 2 分钟侧边栏仍无状态变化，请按以下顺序检查：

1. **查看当前步骤状态**：观察侧边栏是否停留在“正在读取页面”或“正在保存工作流”。如果是复杂的巨型页面，可能需要稍多几秒。
2. **检查账号与配置卡片**：若对话区弹出了以下异常提示卡片，点击卡片对应按钮即可修复：

   | 提示卡片                       | 操作按钮   | 解决方式                               |
   | :----------------------------- | :--------- | :------------------------------------- |
   | 当前 AI 模型还没有配置 API Key | **去配置** | 填写你的自定义 Key，或切回官方默认通道 |
   | 需要登录官网账号               | **去登录** | 完成官网认证以获取编译通道权限         |
   | 额度不足                       | **去充值** | 补充当前账号的编译调用额度             |

3. **精简需求重新提交**：单次让 AI 同时执行过多复杂跨站任务容易导致推理超时。尝试将长需求拆解（如先抓列表），重新发一遍通常能顺利通过。

## 四、网站改版后的应对方式

工作流是**严格匹配当前网页结构**编译生成的。如果目标网站进行了 UI 重构或代码改版，旧的工作流可能会定位失准。

遇到这种情况，无需费力寻找复杂的调试后台，只需回到「**AI 编译生成**」页面，把你的采集需求**对新页面重新发送一遍**，让 AI 依据新版界面生成一份新的工作流即可。
