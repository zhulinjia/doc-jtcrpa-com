# AI 准备任务时会发生什么

发送采集需求后，AI 会查看网页、试着操作，再保存工作流。页面自行滚动、打开详情或切换内容时，先让它完成，暂时不要手动操作目标网页。

## 怎样知道可以继续了

对话里出现带任务名称、说明和运行按钮的工作流卡片，表示任务已保存。然后按教程恢复练习页面，在「**主工作台**」找到该任务并「**手动启动**」。

准备过程中看到样本，不代表整份结果已经采集完毕；正式运行后还要到「**数据存储**」检查结果。

## AI 向你提问

可以选择卡片里的答案，也可以在卡片的输入框中用自己的话回答。例如“只要中间那个列表”“这次只采当前页”。如果页面需要登录，先处理网页，再按提示回答。

## 出现样本对照

对话中可能出现「**清洗预览**」，用于展示几条样本整理前后的变化。看看金额、姓名等是否符合目标即可；最终仍以运行后的表格为准。

## 停在提示或错误上

| 你看到什么 | 下一步 |
| --- | --- |
| 需要登录官网账号 | 按卡片上的「去登录」完成登录，再回到目标页重试 |
| 额度不足 | 按卡片提示查看账号额度和可用方式 |
| 当前 AI 模型还没有配置 API Key | 按提示配置；使用默认通道的用户先检查登录，见[AI 模型配置](/settings/ai-model) |
| 需要开启「允许用户脚本」 | 按[权限提示](/advanced/user-script)开启，返回目标网页后点「已开启」 |
| 需要刷新当前页 | 刷新目标网页，完成后重新发送需求 |
| 仍在处理或重试 | 等待它完成；以是否出现工作流卡片判断是否已保存 |

如果处理停止、仍没有工作流卡片，先记录当前提示，检查页面是否可正常查看。可以告诉 AI“刚才没有完成，请帮我检查”，仍无法继续时按[问题反馈清单](/troubleshooting/)提供现象。
