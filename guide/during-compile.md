# 编译期间会发生什么

发完需求后，AI 在后台具体在做什么？什么情况下会弹出卡片向你提问？了解这些，能帮助你更从容地掌握等待状态。

## 一、AI 在后台处理的三件事

当你点击发送后，AI 会根据需求分析页面、生成工作流。耗时因任务和网络而异，过程中可能包括：

1. **分析网页** —— 识别页面上的列表、内容和按钮。
2. **试采抽样数据** —— 尝试执行一次抓取逻辑，验证能否真实获取你指定的字段。
3. **生成工作流并保存** —— 对话区显示「正在保存工作流…」，生成完毕后自动同步至「主工作台」。

**期间页面可能自动滚动、高亮或点击，属于正常表现**。
**⚠️ 在此期间，请勿手动点击、滑动或关闭该目标网页。**

## 二、什么时候会暂停并向你提问

当 AI 需要你确认信息或完成准备工作时，可能在对话中显示**交互卡片**。请根据卡片内容操作。

回答方式有两种：

- **点击卡片上的候选答案**（推荐，最快捷）。
- **在卡片底部的输入框中手写回答**（提示语为「以上都不合适？直接输入你的答复」），写完后点发送。

完成答复后，卡片会自动折叠收起，并显示「已答复：你的选择」。

常见提问场景如下：

| 触发场景                 | 典型提问示例                                             | 你需要做的操作                         |
| :----------------------- | :------------------------------------------------------- | :------------------------------------- |
| **页面存在多个相似列表** | “页面上识别到左侧推荐列表与右侧主列表，请问采集哪一个？” | 点击确认你要的目标区域                 |
| **需要先完成准备**       | 页面需要登录或切换到指定内容                             | 先在网页中完成操作，再按卡片提示答复   |
| **页面弹窗阻挡**         | 弹窗挡住需要操作的页面                                   | 在网页上手动关掉弹窗，再按提示继续     |

::: tip 自动出现的「清洗预览」卡片
如果你在需求中提到了数据清洗要求（如“去货币符号”或“只要销量大于 100”），对话区可能出现「**清洗预览**」卡片，以「原始数据 → 处理后」的对照形式展示样本效果。

**该卡片仅供核对，上面没有按钮，看完即可，无需操作。** 底部标注的“运行期那遍才是权威”，意味着预览仅为抽样验证，正式运行任务时提取的全量数据才是最终结果。
:::

::: tip 卡住时支持直接放弃
如果不确定如何选择，可以在卡片输入框里说明情况，或通过对话告诉 AI 想调整需求。结束当前处理后，再核对是否有已保存的工作流。
:::

## 三、等待超时或无响应排查

如果侧边栏长时间没有状态变化，请按以下顺序检查：

1. **查看当前步骤状态**：观察侧边栏是否停留在“正在读取页面”或“正在保存工作流”。如果是复杂的巨型页面，可能需要稍多几秒。
2. **检查账号与配置卡片**：若对话区弹出了以下异常提示卡片，点击卡片对应按钮即可修复：

   | 提示卡片                       | 操作按钮   | 解决方式                               |
   | :----------------------------- | :--------- | :------------------------------------- |
   | 当前 AI 模型还没有配置 API Key | **去配置** | 填写你的自定义 Key，或切回官方默认通道 |
   | 需要登录官网账号               | **去登录** | 完成官网认证以获取编译通道权限         |
   | 额度不足                       | **去充值** | 补充当前账号的编译调用额度             |

3. **精简需求重新提交**：单次让 AI 同时执行过多复杂跨站任务容易导致推理超时。尝试将长需求拆解（如先抓列表），重新发一遍通常能顺利通过。

## 四、网站改版后的应对方式

工作流根据当时的网页生成。如果目标网站改版，旧工作流可能会定位失准。

遇到这种情况，无需费力寻找复杂的调试后台，只需回到「**AI 编译生成**」页面，把你的采集需求**对新页面重新发送一遍**，让 AI 依据新版界面生成一份新的工作流即可。
