# 九头虫RPA-Agent 能做什么

它可以把你在网页上反复做的事情，准备成可重复运行的步骤。你用平时聊天的方式说明要什么，AI 查看当前网页，再生成工作流。

例如：“帮我把这一页的书名和价格整理成表格。”你不需要先学编程，也不用把每一次点击都写出来。

## 适合从哪些工作开始

| 你的工作 | 可以先尝试 |
| :--- | :--- |
| 整理商品、订单或文章 | 把网页列表整理成表格 |
| 信息分散在很多详情页 | 打开详情，补齐简介等内容 |
| 已有一份网址清单 | 按 Excel 中的链接逐条处理 |
| 每天整理同样的信息 | 跑通后设置定时任务 |
| 只需要邮箱、电话或图片 | 直接使用对应提取工具 |

登录和验证码通常先手动处理。网站能否采集、能采到多少，要以实际试跑和核对为准。

## 第一次只认三个地方

- **AI 编译生成**：告诉 AI 想做什么，准备或修改工作流。
- **主工作台**：找到已经保存的工作流，点击「手动启动」。
- **数据存储**：预览、检查并下载结果。

准备步骤会使用所选 AI 服务；定时任务、下载等功能还可能有套餐要求，以界面提示为准。数据保存和发送去向见[数据保存与去向](/data/privacy-storage)。
