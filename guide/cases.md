# 按工作目标选择教程

先找一件与你的工作相似的事。各篇教程先在虚构数据上练习，再告诉你怎样换成自己的网页。

| 你想交付什么 | 推荐路线 | 练习完成时检查什么 |
| --- | --- | --- |
| 一份商品或书籍价格表 | [第一个任务](/guide/first-task) → [翻页采集](/tutorial/list-pagination) | 每个标题与价格对应，包含约定的页数 |
| 一份含简介的资料表 | [列表与详情页](/tutorial/list-and-detail) | 每个名称与自己的简介在同一行 |
| 按网址清单整理的表格 | [上传表格，按清单采集](/tutorial/upload-table) | 清单中的网址都有对应结果，能对照来源页 |
| 搜索或筛选后的结果表 | [先搜索和筛选](/tutorial/form-entry) | 搜索条件正确，采集的是搜索后的列表 |
| 一份评论汇总表 | [滚动加载与点击加载更多](/tutorial/infinite-scroll) | 后面加载的评论也包含在内，没有重复采同一批 |
| 已填写的咨询或登记表 | [填写与提交表单](/tutorial/fill-form) | 每个输入和选项符合要求，提交结果正确 |
| 网页上的邮箱、电话或图片 | [提取工具](/tools/extract-tools) | 提取对象与网页内容相符 |

如果已经有结果，接着看[按工作要求整理结果](/data/tidy-results)和[导出数据](/data/export)。需要协作时，再配置[飞书多维表格](/data/feishu)。

先选一条路线完成。做过一次后，可以只看目标和核对标准，自己向 AI 表达需求。
