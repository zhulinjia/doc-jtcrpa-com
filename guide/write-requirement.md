# 像聊天一样提出采集需求

从你想得到的结果说起。第一次不必把每一步操作都安排好，AI 会结合当前网页理解；有不确定的地方，再与你确认。

## 先说一件想做的事

> 帮我把这一页的书名和价格整理成表格。

可以直接在[第一个采集任务](/guide/first-task)里试一次。说话前停留在想处理的网页上，避免 AI 看到的是帮助文档或别的标签页。

## 有自己的要求，再补一句

| 你的想法 | 可以这样接着说 |
| --- | --- |
| 还想要作者 | 再帮我加上作者。 |
| 先少做一点 | 先只整理前 3 条。 |
| 多整理一页 | 把第二页也一起整理进去。 |
| 换表头语言 | 把表格的列名改成中文。 |
| 单独保存结果 | 这次的结果单独存成一张新表。 |
| 价格列没有值 | 价格没有采到，帮我看看。 |

这些补充需要用到哪个网页、哪一个任务，就打开对应页面，从原工作流的「**修改**」进入，见[修改已有工作流](/guide/modify-workflow)。

## AI 问你时怎样回答

按你原本想做的事情回答。例如页面有两个列表，就告诉它“我要中间的商品列表”；范围没说清楚，可以回答“这次只要当前页”。不用猜它希望听到什么。

## 练习：用自己的话说

在书店首页，让 AI 整理前 3 本书的书名和价格。写完、运行后，对照网页核对是否正好是目标中的 3 本。需要参考时看[换成自己的网页](/guide/own-page)。
