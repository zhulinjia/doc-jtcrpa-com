# 安装与首次使用

本篇介绍如何将扩展添加到浏览器中，以及完成首次使用的准备工作。

## 一、安装扩展

推荐优先从官方应用商店安装；若无法访问商店，可使用离线安装包。

### 方式一：从应用商店安装（推荐）

点击对应浏览器的链接进入商店页面，点击「添加至 Chrome」或「获取」即可完成安装。

- **Chrome 应用商店**  
  <a :href="DOWNLOADS.chrome" target="_blank" rel="noreferrer">{{ DOWNLOADS.chrome }}</a>
- **Microsoft Edge 扩展商店**  
  <a :href="DOWNLOADS.edge" target="_blank" rel="noreferrer">{{ DOWNLOADS.edge }}</a>

### 方式二：从网盘下载离线包手动安装

适用于无法打开应用商店，或受公司网络策略限制的环境。

**下载地址**：<a :href="DOWNLOADS.pan" target="_blank" rel="noreferrer">{{ DOWNLOADS.pan }}</a>  
**提取码**：`{{ DOWNLOADS.panCode }}`（若链接未自动带上提取码，请手动输入）

1. 下载压缩包文件（`.zip`）。
2. **解压**该压缩包，会得到一个安装文件夹（请记住解压后的存放路径）。
3. 在浏览器地址栏输入对应地址，按回车打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
4. **开启「开发者模式」开关**（不同浏览器的名称和位置有所不同）：

   | 浏览器     | 开关名称         | 所在位置                               |
   | :--------- | :--------------- | :------------------------------------- |
   | **Chrome** | **开发者模式**   | 页面**右上角**                         |
   | **Edge**   | **开发人员模式** | 页面**左侧菜单栏**（部分旧版在右上角） |

5. 点击「**加载已解压的扩展程序**」（Edge 中为「**加载解压缩的扩展**」；该按钮会在第 4 步打开开关后出现）。
6. 在弹出的文件选择器中，选中第 2 步**解压出来的整个文件夹**，点击确认即可。

<!-- TODO: [截图] 扩展管理页的「开发者模式」开关与「加载已解压的扩展程序」按钮 -->

::: warning 手动安装的注意事项

1. **不会随商店自动更新**：后续发布新版本时，需要重新下载新压缩包并覆盖或重新加载。
2. **启动提示**：部分浏览器启动时可能会提示“请停用以开发者模式运行的扩展”，直接选择保留或关闭提示即可。

:::

## 二、固定图标并激活页面

1. **固定到工具栏**：刚装好的扩展通常会折叠在地址栏右侧的「拼图图标」内。点击拼图图标，找到「九头虫 Agent」，点击旁边的**图钉按钮**，将其固定到浏览器工具栏。
2. **重要：刷新已打开的网页**：  
   刚安装好扩展时，**之前就已经打开的所有标签页需要各自手动刷新一次**，扩展才能注入并正常识别网页内容。

## 三、登录账号

AI 编译工作流需要调用云端模型，登录账号后系统会自动分配初始化编译额度：

1. 打开任意一个你要采集的普通网页（避免停留在空白页或浏览器设置页）。
2. 点击工具栏的九头虫图标，滑出右侧边栏。
3. 点击侧边栏最下方的「**设置菜单**」，此时会显示「未登录账号」。
4. 点击「**立即登录 / 注册**」，浏览器会打开官网认证页。完成登录或注册后，关闭该页返回原网页。
5. 再次点击「设置菜单」，能看到个人昵称与套餐状态即代表登录成功。

![设置菜单弹层：顶部是「未登录账号」和「立即登录 / 注册」，往下是「AI KEY 配置」「飞书多维表格」](/images/sidebar-settings-menu.png)

弹层顶部是账号状态。未登录时这里写着「**未登录账号**」，点「**立即登录 / 注册**」去登录；
登录成功后再点开，这里会换成你的昵称和套餐状态。

![登录后的「设置菜单」：顶部显示昵称、套餐与到期日、充值额度与赠送额度，中间是「退出登录」，下面是「AI KEY 配置」「飞书多维表格」](/images/sidebar-settings-loggedin.png)

登录后这个弹层会变成上图这样（图中账号名已打码）：顶部是你的**昵称**、**套餐与到期日**、**充值额度**和**赠送额度**，
中间多出一个「**退出登录**」按钮。看到昵称就说明登录成功了。

## 四、AI 模型配置（新手可跳过）

登录完成后，系统**默认使用官方 AI 通道**，无需做任何技术配置即可直接使用。

如果你有自己的模型 API Key（如 DeepSeek、OpenAI 等），可以在「设置菜单」中自行接入并切换。初次上手**建议直接跳过此项**。
