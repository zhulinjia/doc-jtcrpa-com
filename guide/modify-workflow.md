# 编译期间会发生什么

发完需求后，AI 在后台具体在做什么？什么情况下会弹出卡片向你提问？了解这些，能帮助你在等待时心里更有数。

## 一、AI 在后台处理的三件事

当你点击发送后，系统通常会在 **15 ~ 40 秒** 内依次执行：

1. **分析网页结构** —— 读取当前页面的整体排版布局，识别列表区域、正文块以及翻页/加载按钮。
2. **试采抽样数据** —— 尝试执行一次抓取逻辑，验证能否真实获取你指定的字段（如标题、价格）。
3. **生成工作流并保存** —— 对话区显示「正在保存工作流…」，生成完毕后自动同步至「主工作台」。

整个编译过程全部自动进行。**期间页面会自动滚动、高亮选块或模拟点击，均属正常表现**。

::: warning ⚠️ 编译期间的唯一禁忌
**请保持停留在该网页上，不要切换到其他标签页，也不要在网页里手动乱点。**  
如果切到别的标签页，浏览器可能会暂停当前页面的动态渲染，导致 AI 抓取中断或超时。
:::

## 二、什么时候会暂停并向你提问

只有当页面结构存在多种可能、AI 拿不准时，它才会在对话区弹出一张**交互卡片**。卡片顶部是具体问题，下方配有候选答案。

回答方式有两种：

- **点击候选答案**（推荐，最快最省事）。
- **手写自定义回答**：如果候选选项都不合适，在卡片底部的输入框直接输入补充说明（如输入“只要右边那一栏”），点发送即可。

答完后，卡片会自动折叠收起，并显示「已答复：你的选择」。

常见提问场景如下：

| 触发场景                 | 典型提问示例                                           | 你需要做的操作                       |
| :----------------------- | :----------------------------------------------------- | :----------------------------------- |
| **页面存在多个相似列表** | “页面上识别到左侧推荐列表与右侧主列表，请问采哪一个？” | 点击确认你要的目标区域               |
| **存在同名工作流**       | “检测到你已有名为‘商品采集’的工作流，要引用哪一个？”   | 点击你要引用的那张卡片               |
| **需要前置页面状态**     | “当前数据需要登录后可见，或需要切到特定标签”           | 在网页中手动操作完毕后，点「已就绪」 |
| **页面弹窗阻挡**         | “检测到营销弹窗或活动遮罩遮挡了翻页按钮”               | 在网页上手动关掉弹窗，随后点继续     |

::: tip 自动出现的「清洗预览」卡片
如果你在需求中写了过滤或清洗要求（如“价格去掉货币符号”或“只要销量大于 100”），编译时会弹出一张「**清洗预览**」卡片，用「原始数据 → 清洗后」的对照展示效果。

**这张卡片仅供核对，上面没有操作按钮，看过即可。** 卡片底部注明的“运行期那遍才是权威”，意思是预览只是抽样展示，正式运行任务时提取的全量数据才算数。
:::

::: tip 拿不准怎么选？
如果不确定该选哪个，可以直接在卡片输入框里打字回复：

- **「按你推荐的来」**：让 AI 自动按概率最高的方案走。
- **「先不弄了」**：退出本次编译，重新梳理需求。

:::

## 三、等待超时或报错排查

正常编译耗时一般在 1 分钟以内。如果遇到异常，按以下顺序排查：

### 1. 超过 2 分钟无响应

- **看侧边栏停在哪一步**：观察是否停留在“正在读取页面”或“正在保存工作流”。部分大型复杂的页面可能需要多等十几秒。
- **检查网络与页面是否假死**：如果整个网页无反应，刷新页面并重新发送一次需求。

### 2. 对话区弹出配置卡片

若弹出以下卡片，通常点击对应按钮即可恢复：

| 提示卡片                       | 操作按钮   | 解决方式                               |
| :----------------------------- | :--------- | :------------------------------------- |
| 当前 AI 模型还没有配置 API Key | **去配置** | 填写你的自定义 Key，或切回官方默认通道 |
| 需要登录官网账号               | **去登录** | 完成官网登录，恢复编译额度             |
| 额度不足                       | **去充值** | 补充当前账号的 AI 调用额度             |

### 3. 明确提示“编译失败 / 未找到目标”

- **把需求改得更具体**：不要一次性塞入太多复合要求。例如将“采商品信息、点进详情页再把推荐商品也采了”拆开，先只说“采集当前列表的商品标题和价格”。
- **确认页面是否完全加载**：有些瀑布流网站刚打开时内容是空的，等列表完全渲染出来后再发需求。

## 四、网站改版后的应对方式

工作流是**严格匹配当前网页结构**编译生成的。如果目标网站进行了改版或重新排版，旧的工作流可能会失效。

此时**不需要去找任何复杂的代码调试后台**：
直接在浏览器打开改版后的新网页，回到「**AI 编译生成**」页面，把你的需求**重新发送一遍**，让 AI 依据新页面重新编译生成一张新工作流即可。
