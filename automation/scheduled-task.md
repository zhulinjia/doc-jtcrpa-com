# 定时任务

支持按预设的时间周期，全自动在后台唤起工作流执行采集。

::: tip 兼具计划调度与批量采集
「定时任务」不仅支持“每天定点自动跑”，也是**批量处理多条网址的执行器**。如果需要一次性抓取 100 个同类页面，即便不需要周期循环，也可以在这里配好网址并直接点「立即执行」。详见[批量采集](/automation/batch-collection)。
:::

::: warning 会员功能说明

- **配置不需要会员**：新建、编辑、导入导出网址和开关任务不需要会员。执行测试仍需满足下方的会员要求。
- **执行需 VIP1 及以上**：无论到点自动触发，还是手动点击「立即执行」，启动时都会检查会员权限。若任务未触发，先在「**设置菜单**」里查看账号和会员状态。

:::

## 一、新建定时任务

点击侧边栏导航中的「**定时任务**」，点击右上角「**新建任务**」进入配置页。

### 表单配置项详解

1. **任务名称**：输入用于自我识别的标题（例如：`每日大宗商品价格监控`、`竞品销量日报`）。
2. **目标网址**：
   - 填入要采集的 URL，一行一个。
   - 支持直接从 Excel 复制整列批量粘贴，或点击「**导入 TXT / CSV**」载入文件。
   - 单任务最多支持填入 **5,000 个网址**，上方会实时统计已识别链接数。
3. **关联工作流**：
   - 从下拉框中选中你此前已经调试跑通的工作流。
   - 选中后，下方会清晰展示该工作流的动作步数与需求摘要，供二次核验。
   - **数据去向**：数据按所选工作流的配置保存；如果工作流使用本地数据集，已有数据通常会累积。详见[数据存储与数据预览](/data/storage-preview)。
4. **调度设置**：配置触发时间与频率（见下文）。

配置完成后，点击底部的「**保存任务**」。

## 二、频率设置：10 种周期选择

点击「频率」下拉菜单，系统内置了覆盖主流业务场景的 10 种周期：

| 调度频率                | 适用场景                                     | 关键配置项                       |
| :---------------------- | :------------------------------------------- | :------------------------------- |
| **每 5 / 10 / 30 分钟** | 高时效监控（如实时抢购、库存变动、秒杀预警） | 无需额外配置，保存即刻生效       |
| **每小时**              | 日内多次轮巡监控                             | 每隔约一小时触发一次             |
| **每 6 小时 / 12 小时** | 每日固定批次汇总                             | 固定间隔触发                     |
| **每天（默认选项）**    | **最常用**。每日报表汇总                     | 设定具体执行时间（默认 `08:00`） |
| **每周**                | 周报或周度数据复盘                           | 设定周几（默认周一）与执行时间   |
| **每月**                | 月度统计与财务对账                           | 设定每月几号与具体时间           |
| **自定义 cron**         | 面向资深用户的复合时间表达式                 | 填写标准 5 段式 cron             |

::: tip 为什么每月只有 1~28 号可选？
系统排除了 29、30、31 号，避免某些月份没有对应日期。选择 **28 号**可以保证每个月都有这个日期，但它不等于每月最后一天。
:::

## 三、自定义 cron 表达式（选填）

选择「自定义 cron」后需填入标准的 **5 段式 cron 表达式**（格式：`分 时 日 月 周`，默认值为 `0 8 * * *`）：

| 常用表达式示例 | 执行规律解读                            |
| :------------- | :-------------------------------------- |
| `0 9 * * 1-5`  | 每周一至周五早上 09:00 执行，不区分节假日和调休 |
| `0 * * * *`    | 每小时的 00 分整点触发一次              |
| `30 23 * * *`  | 每天深夜 23:30 触发                     |

_注：若不熟悉 cron 语法，直接使用预设的「每天/每周」效果完全一致，无需勉强使用。_

## 四、卡片管理与快捷操作

保存后的任务以卡片形式呈现在列表页中：

- **右上角开关**：控制「到点是否自动触发」。关闭后该任务进入暂停状态。
- **「立即执行」按钮**：不受定时时间和开关状态限制，尝试启动一次；仍需满足会员等启动条件。
- **「编辑」**：调整任务绑定的工作流、网址清单或修改触发周期。
- **「下载任务包」**：将当前任务及其绑定的工作流整体打包导出为一个备份文件，方便迁移到其他电脑。
- **「查看运行日志」**：新标签页打开历史调度记录与详细步进日志。
- **「删除此任务」**：彻底移除该计划任务（不会影响已沉淀的数据与工作流）。

::: tip 停用的任务也能点「立即执行」
启用开关只控制到点是否自动执行。停用时仍可点「立即执行」，启动时同样会检查会员权限和运行状态。
:::

## 五、定时触发的底层机制与表现

1. **自动调起前台标签页**：  
   时间到达时，浏览器会自动弹出新标签页加载目标网址并开始采集。**这是为了防止后台挂起导致页面被浏览器省电机制冻结，并非异常弹窗。**
2. **跑完自动安全关闭**：  
   任务正常结束时，扩展会关闭本次运行打开的标签页；异常时请检查页面和运行日志。
3. **重叠防护机制（漏一拍原则）**：  
   如果上一轮采集任务尚未完全结束，下一轮到点时会**主动跳过**，绝不会排队重叠运行，避免把浏览器跑崩溃。
4. **关机或浏览器关闭期间**：
   到点时电脑和浏览器需要能运行扩展。错过的任务能否在恢复后触发取决于浏览器状态，**不要依赖自动补跑**。重新打开浏览器后请查看运行日志，确认是否执行；需要补采时可手动点击「立即执行」。

## 六、定时任务未触发排查指南

如果到了设定时间任务没有执行，请按以下顺序逐项核对：

1. **核对卡片开关**：确认任务卡片右上角的总开关处于开启（高亮）状态。
2. **核对会员状态**：打开侧边栏「设置菜单」查看会员套餐是否已到期。若已过期，任务会自动停摆。
3. **核对工作流有效性**：观察卡片上是否出现「**工作流已删除**」黄色警告标签。如果绑定的工作流已被删除，需点击「编辑」重新指定新工作流。
4. **查收系统通知并查看日志**：会员权限不足时可能收到「**定时任务未执行**」通知；其他情况不一定有通知，请结合任务状态和[执行日志](/automation/run-logs)检查。
