# 定时任务

想每天把同一类网页整理一遍，可以让已经跑通的工作流按时间执行。**先手动试跑成功，再设置定时。**

电脑需要开机，浏览器和扩展需要能运行，网页需要保持可访问。定时任务由你的浏览器执行。关机、睡眠或关闭浏览器后，不要依赖它按时运行或自动补跑。

## 先设置一个小任务

1. 在侧边栏进入「**定时任务**」，点击「**新建任务**」。
2. 在「**任务名**」写一个容易辨认的名字，例如“每天的书价”。
3. 在「**目标网址**」粘贴要处理的完整网页地址，一行一个。第一次先放一个。
4. 在「**工作流**」中选择已经在这类页面上跑通的工作流。
5. 在「**调度设置**」选择「**每天**」，填好时间，再点「**保存任务**」。

保存后，检查任务卡片的开关和「下次运行」时间。先点一次「**立即执行**」，到「数据存储」核对结果，并在「日志」检查是否跑完。首次到点运行后，也再核对一次。

::: tip 费用与权限
保存设置和执行任务的权限不同。定时执行及「立即执行」需要 VIP1 或以上；实际能否执行，以界面显示的账号和套餐权限为准。
:::

## 怎样暂时不让它自动跑

关闭任务卡片右上角的开关即可。**关闭开关后仍能点击「立即执行」手动跑一次。**

新建任务默认启用。如果你只想处理一批网址，保存后及时关闭开关，详见[一次处理一批网址](/automation/batch-collection)。

## 其他频率按需要选

支持每隔若干分钟或小时、每天、每周和每月。每月可选 1～28 号；28 号表示每月 28 日。自定义时间表达式是进阶选项，不熟悉时使用现成周期即可。

任务运行时会打开采集标签页，正常结束后通常会关闭本次打开的页面；请留给它操作。上一轮还在运行时，下一轮可能被跳过。结果按关联工作流的设置保存，可能与历史数据放在同一张表里。

## 到点没跑，按这个顺序查

1. 任务开关有没有开启？「下次运行」时间是否符合预期？
2. 电脑是否睡眠，浏览器是否关闭，网络是否正常？
3. 账号与会员是否有效？任务是否显示「工作流已删除」？
4. 打开「**日志**」确认有没有启动、在哪一步停止。

提示需要同步时点击「**重试同步**」；提示执行配置缺失时，编辑任务，重新选择工作流并保存。需要补跑，再点「立即执行」，先注意之前是否已有部分结果。

希望失败或等待处理时收到邮件，可以设置[邮件提醒](/automation/notifications)。长期运行还请看[防休眠](/troubleshooting/anti-sleep)。
