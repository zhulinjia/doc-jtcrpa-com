# 启动、中断与结束

工作流准备好后，在「主工作台」找到它。先把浏览器切回要处理的网页，再点击「**手动启动**」。AI 准备步骤和正式运行是两件事；看到工作流卡片后，还需要启动一次。

## 运行时怎么操作

卡片上的「正在执行」告诉你目前在做什么。需要处理登录或其他障碍时，它可能变成「已挂起」。提示中说的“运行卡”，就是工作流卡片底部这块控制区。

| 按钮 | 什么时候用 |
| :--- | :--- |
| **中断** | 暂停这次运行，保留继续的机会 |
| **恢复** | 处理完页面上的问题后，接着运行 |
| **跳过** | 放弃当前整个步骤，继续后面；可能漏数据或影响后续操作，先看确认说明 |
| **结束** | 终止这次运行，之后需要重新启动；点下就会停止 |

“跳过”不一定只跳过一行记录。不确定时先处理障碍，再点「恢复」。有些位置不能单独跳过，请按提示恢复或结束。

运行期间保持网页可见，不要关闭采集标签页。长任务见[防止电脑与网页休眠](/troubleshooting/anti-sleep)。

## 想从网页右键启动

点击「手动启动」右边的小箭头，在「切换触发方式」中选择「**设为右键执行**」。卡片变为「**右键已启用**」。

接着到目标网页上点击鼠标右键，在菜单中选择这个工作流的名称。卡片上的「右键已启用」用来查看说明；启动操作在网页右键菜单里。

同一时间只能有一个工作流使用这种方式。给另一个工作流启用后，前一个会让位。想恢复原来方式，在小箭头菜单中选择「手动启动」。

## 跑完以后

启动按钮重新出现，说明本次运行已经结束。到「**数据存储 → 预览**」核对结果；成功提示只能说明步骤执行完，不保证数据符合你的需求。

运行失败，或不知道是否跑完时，点击卡片上的「**日志**」，查看[执行日志](/automation/run-logs)。已经写入的数据可能仍然保留，重新运行前先检查，涉及提交表单或发送数据时尤其如此。

需要每天自动跑，继续看[定时任务](/automation/scheduled-task)；中途停住，查看[运行中断了怎么办](/troubleshooting/interrupted)。
