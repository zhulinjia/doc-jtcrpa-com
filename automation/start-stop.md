# 启动、中断与结束

工作流卡片底部那块控制区，左边是启动键，右边是一排小图标。
本篇讲怎么开跑，以及中途怎么中断、恢复、跳过和结束。

::: tip 界面上还会叫它「运行卡」
运行挂起时，侧边栏会弹这么一句：

> 运行已挂起：处理完页面障碍后，在**运行卡**点「恢复」或「结束」（AI 诊断：xxx）

里面的「**运行卡**」指的就是**工作流卡片底部这块控制区**——同一个地方，界面在提示里用了这个名字。
:::

## 先认位置：工作流卡片底部

在「**主工作台**」的每张工作流卡片底部。左边是启动键，右边是一排小图标。

| 位置 | 有什么 |
| :--- | :--- |
| 左边 | **启动键**（带一个下拉小箭头）——点它就开跑 |
| 右边 | 四个小图标：下载此工作流、在聊天中修改此工作流、查看运行日志、删除 |

鼠标停在图标上会显示它叫什么。这排图标的样子下文都会用到，先认个位置就行。

## 启动：两种触发方式

点启动键左边那块就开始采集。点它右边的小箭头会展开一个下拉，标题写着「**切换触发方式**」，
里面**只有两项**：

| 选项 | 选中后启动键显示 | 怎么用 |
| :--- | :--- | :--- |
| **手动启动** | 「手动启动」 | 默认。点一下就跑**你当前打开的那个网页** |
| **设为右键执行** | 「右键执行」 | 之后在网页上点右键，菜单里就有这个工作流，点它执行 |

<!-- TODO: [截图] 「切换触发方式」下拉，只有两项 -->

::: warning 「右键执行」同一时刻只能有一个工作流
切换是**抢占式**的：你给另一个工作流也切成「右键执行」，前一个就自动让位了。

右键菜单里出现的文字**就是工作流名**，所以你看一眼就知道现在挂的是哪一个。
:::

::: tip 定时任务不在这里
「**定时任务**」是独立的一页，不在这个下拉里。见[定时任务](/automation/scheduled-task)。
:::

### 用「右键执行」时的两点

- 右键菜单里的文字是**工作流名**，名字太长会被截断，但认得出是哪一个。
- **侧边栏没开着也能执行。** 万一没启动起来（比如页面找不到了），提示会走浏览器的系统通知；
  跑的结果则去「数据存储」和[执行日志](/automation/run-logs)里看。

想切回来，就在下拉里重新选「手动启动」。

## 运行中，卡片上会多一行小字

它告诉你此刻在干什么：

| 显示 | 意思 |
| :--- | :--- |
| **正在执行：** + 当前这一步 | 正常跑着 |
| **已挂起：** + 当前这一步 | 停下来**等你处理**了。见[运行中断了怎么办](/troubleshooting/interrupted) |
| **准备中…** | 刚启动，还没轮到具体步骤 |

同时**启动键那一组会暂时收起**，跑完才回来。这样卡片不会在你连点时重复启动。

## 四枚按钮：中断 / 恢复 / 跳过 / 结束

它们**按运行状态自己出现和消失**，你不用记什么时候该有哪几个：

| 按钮 | 什么时候出现 | 作用 |
| :--- | :--- | :--- |
| **中断** | 运行中 | **暂停，保留进度**。之后可以点「恢复」接着跑 |
| **恢复** | 挂起时 | 从停下的地方继续 |
| **跳过** | 挂起时 | 丢掉当前这一步，继续跑后面的。**会先弹确认框** |
| **结束** | 运行中、挂起时 | **中止**这次运行，不能接着跑 |

::: warning 「中断」不是「结束」
「中断」是暂停，随时能恢复；「结束」是终止，**结束了就接不回去**。

「结束」是红色那枚，而且**没有二次确认**——点了就停。
:::

::: warning 「跳过」会丢掉这一步的数据
点「跳过」会先弹一个确认框，把后果写清楚：

> **跳过当前步骤？**
> 本步不会执行——该做的动作没做、该采的数据没采；运行直接继续下一步，
> 后续步骤可能因此失败。

**这一步该采的数据就不采了**，后面的步骤还可能跟着出错。拿不准就用「恢复」。
:::

### 偶尔「跳过」点不动

如果它提示「**当前挂起处是引擎内部步骤，没有可跳过的步骤——请用「恢复」继续**」，
说明卡住的位置不是一个能单独跳过的步骤。**这时只有恢复或结束两条路**——按钮没坏。

## 跑完之后

运行结束（无论成功还是失败）时，卡片会**回到刚打开的样子**：启动键又变回可点，卡片上不留跑过的痕迹。

所以有两件事要知道：

- 成功会弹一句「**工作流已完成**」，失败会弹一句「**工作流执行失败**」。
- **失败的具体原因卡片上不说**，得去日志里翻。见[执行日志](/automation/run-logs)。

> 想再跑一次，直接点启动键就是重跑，不用先做什么"复位"。

## 运行期间请注意

::: warning 别最小化窗口
浏览器会休眠很久没看的页面。被休眠的页面**采出来是空的，而且不一定报错**。

详见[长时间采集防休眠](/troubleshooting/anti-sleep)。
:::
