# 工作流邮件提醒

任务需要你处理，或运行失败时，可以发邮件提醒你。先设置自己的邮箱，再用测试邮件确认能收到。

## 设置并试收一封邮件

1. 打开扩展底部的「**设置菜单 → 通知设置**」。未登录时，先按提示登录官网账号。
2. 在「**邮箱地址**」填自己的收件邮箱，点击输入框外面。修改后自动保存。
3. 点击「**测试发送**」。看到“测试邮件已提交，请检查收件邮箱”后，打开邮箱检查收件箱和垃圾邮件。
4. **实际收到邮件，才算验证送达。** 提交成功仅表示发出了发送请求。测试后需要等待倒计时结束，才能再次发送。

本教程的测试邮件已经通过实际 QQ 邮箱确认收到。不同邮箱仍需各自测试；这里无需填写邮箱密码。

## 哪些情况会提醒

| 情况 | 设置方式 |
| :--- | :--- |
| 等待处理或运行失败 | 填好邮箱后默认提醒 |
| 正常完成也想收到 | 打开「**工作流正常完成时**」开关 |
| 自己点击中断或结束 | 不发送这类提醒 |
| 想关闭邮件提醒 | 清空「邮箱地址」，点击输入框外面并确认保存状态 |

提醒适用于工作流，可能包含任务名称和异常信息；请使用适合接收这些内容的邮箱。

## 收不到，先检查什么

确认邮箱拼写和页面保存状态，检查垃圾邮件，再查看工作流是否真的触发了所选提醒时机。电脑关机、浏览器关闭或持续断网时，扩展无法及时发送提醒。

收到异常提醒后，回到浏览器处理目标网页。如果任务仍在挂起，处理后点击「**恢复**」；已经结束的任务先查看[执行日志](/automation/run-logs)，确认已完成哪些内容，再决定是否重新运行。
