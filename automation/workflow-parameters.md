# 参数节点与启动参数

同一个工作流可以按不同的关键词、筛选条件或页数重复运行。告诉 AI 哪些值要在每次启动时填写，AI 会在工作流的第一步添加「参数」节点。后续步骤会使用这次启动时提供的值。

## 用书店练习采集不同页数

1. 打开<a href="/practice/index.html" target="_blank" rel="noopener noreferrer">书店练习场首页 ↗</a>，在该页打开扩展侧边栏，进入「**AI 编译生成**」。
2. 发送下面的采集需求。

   > 采集书名和价格，每次开始前让我填页数。

3. 回到书店首页，在「**主工作台**」找到刚生成的工作流并点击「**手动启动**」。在「**填写运行参数**」里填 2 页，再点击「**开始执行**」。
4. 跑完后，核对本次有没有采到第二页的《旅途中的小地图》。[检查本次采集结果](/data/check-results)

## 怎样填写参数或修改默认值

- 手动启动时，有默认值的字段会预先填入。可以保留，也可以改成这次要用的值。标为「**必填**」的字段按界面提示填写。
- 按字段旁的类型填写。关键词用「文本」，采集页数用「数字」，开关用「布尔值」并选择「是」或「否」。工作流也可以使用「JSON」类型的输入。
- 要增加参数或长期修改默认值，在工作流卡片点「**修改**」，说明要改哪一项。例如「把采集页数的默认值改成 2，每次启动时仍然可以改」。[修改已有工作流](/guide/modify-workflow)

## 其他启动方式怎样提供参数

| 启动方式 | 怎样提供参数 |
| --- | --- |
| 定时任务 | 选中工作流后，在「**工作流参数**」里填写并保存。这条任务到点执行和点击「**立即执行**」都会使用保存的值。[定时任务参数](/automation/scheduled-task#workflow-parameters) |
| MCP | 在 Codex 或 WorkBuddy 里告诉 AI 要运行哪条工作流，再说「这次采 2 页」。[MCP 连接指南](/advanced/mcp) |
| 网页右键执行 | 使用工作流的默认值。需要填入本次值时，在工作流卡片的下拉菜单中切回「**手动启动**」。 |

如果一个工作流调用另一个工作流，也可以在采集需求里说明该把哪个值传给它。[组合使用多个工作流](/tutorial/workflow-invocation)
