# 执行日志

每次运行都会留下一份详细日志。采集结果不对、或者想弄清它跑到哪一步时，来这里看。

## 怎么打开

**主工作台的工作流卡片 -> 点「查看运行日志」图标**（鼠标停上去会显示这个名字）。
「定时任务」的卡片上也有同一个按钮。

日志页会在**浏览器的新标签页**里打开，不在侧边栏里。

## 一篇日志 = 一次运行

页面顶部是标题「**执行日志**」，旁边有个下拉可以换看哪一次运行——点开是「工作流名 · 日期 时间」的列表，
进去时默认显示**最近一次**。

运行很多时，下拉只列最近一批，底部有一行「仅显示最近 N 条 · 共 M 条，点击加载更早」，点它往下翻。

下拉右边是这一次运行的信息条：一个状态圆点 + 工作流名 + 时间 + 一枚状态标签。

状态标签有五种：**运行中**、**已暂停**、**已完成**、**已失败**、**就绪**。

## 顶部四个读数怎么读

| 读数 | 意思 |
| :--- | :--- |
| **共 N 行** | 这次运行一共写了多少行。**只在日志太长、没全部显示出来时才出现** |
| **执行 N** | 普通步骤的行数 |
| **警告 N** | 有状况但被兜住的行数（琥珀色） |
| **异常 N** | 出错的行数（红色） |

::: tip 有「异常」不等于这次运行失败了
**红色只说明那一行出了错**，运行可能照样跑完了。

判断成败要看状态标签（已完成 / 已失败），以及数据里到底有没有东西。
:::

## 一行日志由什么组成

每行从左到右是：**时间 · 一枚短标签 · 这一步在做什么**。

- 短标签写着这一步的**动作类型**；有些行是「开始」「暂停」「结束」这类整体状态。
- 行尾还会缀上是**哪一页**（标签页编号和网址）——跨页采集时，靠它分辨这句话说的是哪个页面。
- 偶尔能看到一枚灰色的「**引擎实例更换**」。这是**中性标记，不是错误**：说明浏览器回收过一次后台进程，
  日志从这一行起由新实例接着写。长运行里出现它很正常。

## 三种「看着像出错、其实正常」的行

日志里最容易被误读的就是这几行：

| 你看到的 | 其实是什么 |
| :--- | :--- |
| 「累计执行 N 步（N 个节点），已落库 N 行」 | **心跳**，说明它还在跑，不是报错 |
| 「运行页被浏览器休眠（后台标签页），心跳自检本拍跳过」 | 页面被浏览器休眠了。见[长时间采集防休眠](/troubleshooting/anti-sleep) |
| 「「某某」失败已被容错块兜住，块内剩余步骤未执行」 | **设计好的降级**：这一步有备用方案，兜住了，不是运行失败 |

## 看某一步的细节

鼠标停在**有内容的**行上会提示「**展开详情**」，点一下展开，能看到这一步的两块内容：**参数**和**结果**。
再点一下收起（提示变成「**收起详情**」）。

每块右上角有个「**复制**」按钮，点一下就把这块内容复制走，按钮会短暂变成「已复制」。

::: tip 反馈问题时请复制，别只截屏
截图经常缺信息。把相关那几行**展开后复制**，或者直接导出整份日志（见下），我们能一次看清楚。
:::

## 导出、删除与清空

顶部右侧有三个按钮：

| 按钮 | 作用 |
| :--- | :--- |
| **导出 .log** | 把这次运行的**完整**日志存成文件。日志很长时旁边会显示进度（已导出多少行） |
| **删除此运行日志** | 删掉当前这一次运行的记录与日志，会先弹确认框 |
| **清空日志** | 把能删的运行日志都删掉，会先弹确认框 |

三点要注意：

- **正在跑或挂起的运行删不掉**——「删除此运行日志」这个按钮干脆不显示。这是有意的：
  那份记录是它恢复现场要用的。
- 「清空日志」**不碰正在执行的运行**，确认框里也是这么写的。
- 删掉**不可恢复**。

> 从工作流卡片点进来时，「清空日志」只清**这个工作流**的；直接打开日志页时，清的是全部。

## 日志太长看不动

页面只显示**最近一段**。往上翻，最上面有个「**加载更早的 N 行**」按钮，点一次往前多要一段。

要完整内容就点「**导出 .log**」——导出来的文件是**逐行完整**的。

## 看不到内容时

- 「**暂无运行记录**」——这个工作流还没跑过，或者记录都被删了。
- 「**该运行暂无日志**」——这一次运行确实没写下任何一行。
