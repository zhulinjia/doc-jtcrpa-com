# AI model and key settings

For your first task, sign in and use **Official AI API**, the default service. If the account has available credits, you can start [your first collection](/en/guide/first-task) without obtaining your own API key.

Use the settings below when you want to connect an AI service you have purchased separately.

## Use your own key

1. Open **Settings → AI key settings** to reach the **AI model service center**.
2. Find your provider and enter its **API Key**. Fill in only the provider you want to use.
3. Changes save automatically. Use **Show** and **Hide** to check an entry.
4. Return to **Compile with AI**, select the service and model from the dropdown below the input, and try a small request.

An API key is a provider access credential, not a website password. Keep it out of requests, screenshots, and shared workflows. This page has no connection-test button; send a small request to check the service.

## Connect another provider

For a service compatible with OpenAI, open **Custom AI provider → Add**. Enter the provider name, API address, model name, and key supplied by that service, then click **Add**.

Select it in the conversation afterwards. The current interface requires removing and adding the entry again to change its name, address, or model; an existing key can be edited directly. Use the provider information supplied by the service.

## Credits are available, but requests still fail

Website account credits and credits purchased from other AI providers are separate. First check which service and model are selected, then check the corresponding account, key, balance, and connection.

| Prompt | What to check |
| --- | --- |
| No API key configured for the current AI model | Click **Configure**, or select the default service with available credits. |
| Sign-in required | Use **Sign in** for the official service. For your own key, also check the selected provider and key. |
| Not enough credits | Check the selected service balance; add credits or choose another configured service if needed. |
| Busy service or timeout | Save the request and retry later. If it persists, record the full message for support. |

Use one page of the practice bookshop to check the connection before processing a large task on your own website.
