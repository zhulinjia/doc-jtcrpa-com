# While AI prepares your task

After you send a collection request, AI examines the page, tries actions, and saves a workflow. Let it finish while the page scrolls, opens details, or changes content.

## Know when the task is ready

A workflow card with a task name, description, and run button means the task is saved. Restore the practice page as the tutorial describes, then use **Manual start** in **Workbench**.

Samples shown during preparation are not the complete collected result. Check the final table in **Storage** after a proper run.

## When AI asks a question

Choose an answer on the card or reply in your own words, for example “Use the middle list” or “Only the current page.” If the page needs sign-in, handle it on the website, then answer the prompt.

## A sample comparison appears

**Cleaning preview** may show how a few sample values will change. Check names, amounts, and other relevant fields. The table produced after the run is the final result to verify.

## A prompt or error stops progress

| What you see | What to do |
| --- | --- |
| Sign-in required | Use **Sign in** on the card, then return to the target page and retry. |
| Not enough credits | Check the account credits and available service options shown on the card. |
| No API key configured for the current AI model | Follow the configuration prompt. If you use the default service, check sign-in first. See [AI model settings](/en/settings/ai-model). |
| A user-script permission is needed | Follow [the permission instructions](/en/advanced/user-script), return to the target page, and click **Enabled**. |
| The current page needs a refresh | Refresh the target webpage and send your request again. |
| AI is still processing or retrying | Wait. The saved workflow card is the sign that it is ready. |

If processing stops without a workflow card, record the prompt and check that the page can be viewed normally. You can say “The previous attempt did not finish. Please check.” If you still cannot continue, use the [problem report checklist](/en/troubleshooting/).
