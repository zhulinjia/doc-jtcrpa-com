# Describe what to collect

Start with the result you want. You do not have to plan every click. AI uses the current page and asks you when something is unclear.

## Start with one task

> Collect the book titles and prices on this page

Try it in [Your first collection](/en/guide/first-task). Before sending the request, switch to the page you want to process so AI examines the right tab.

## Add your own requirements

| What you want | What you can say |
| --- | --- |
| Include authors | Add the author. |
| Start small | Collect only the first 3 items for now. |
| Include another page | Include the second page. |
| Change column names | Change the column names to English. |
| Keep a separate result | Save this run in a separate new table. |
| Fix missing prices | The prices are missing. Please check. |

Open the relevant page and use **Edit** on the saved workflow to make these changes. See [Edit a saved workflow](/en/guide/modify-workflow).

## Answer AI in your own words

Answer according to the work you want to do. If there are two lists, say “Use the product list in the middle.” If the scope is unclear, say “Only the current page this time.”

## Try your own wording

On the bookshop home page, ask for the titles and prices of the first 3 books. Run the task and check that exactly those 3 books were collected. For more guidance, see [Use your own webpage](/en/guide/own-page).
