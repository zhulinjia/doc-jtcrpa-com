# Use your own webpage

Once you have a table from the practice bookshop, open a webpage you use for work. Start with two or three records and check whether the result meets your needs.

## 1. Open a page with visible content

Sign in to the website yourself if needed. Open the list or section you want and make sure you can see the target content.

Open the extension on that page. Browser settings and store pages may block extension actions; see [Unsupported page or refresh required](/en/troubleshooting/page-not-supported). Images and scanned documents may also need a different approach. Check a small sample to see what the page supports.

## 2. Say what you want to collect

In **Compile with AI**, try:

> Collect the product names and prices on this page. Start with the first 3 items.

Replace the columns with the information you actually need. If AI asks you to choose a list or clarify the task, answer according to your goal.

For a new website and a new task, click **New chat** above the conversation. To change a saved task, use **Edit** in Workbench.

## 3. Run and compare with the webpage

Once the workflow card appears, return to the agreed starting page and click **Manual start** in Workbench. Open **Preview** in Storage and compare each sample row with the page. See [Check your results](/en/data/check-results).

If a column is missing, click Edit and say “Add the store name.” If values are wrong, describe the difference you see.

## 4. Collect more

When the sample is correct, add a request such as “Include the first two pages.” Run again and check the result. Different websites have different layouts; check or recreate a workflow when moving it to another website.

## Try your own request

Choose a page you use regularly and decide which columns you need. Collect 3 records first. When you can explain where each value came from on the page, increase the scope.
