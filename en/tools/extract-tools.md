# Extract emails, phone numbers, and images

Use the standalone tools when you only need emails, phone numbers, or images from the current page. They do not require an AI-generated workflow or use AI preparation credits.

Results may include contact details from data loaded by the page. Check which items you actually need before saving.

## Try the practice page

<PracticeTask lesson="contacts" />

Keep the practice page in the current tab and open the sidebar. All three tools are in its feature navigation. The contact details are fictional; no email or phone call is needed.

## Email extractor

Open **Email extractor**. It usually extracts from the current page automatically. Use **Extract email addresses from this page** to retry. Check **3 different addresses**, including **reader@example.com**.

Click **Download all** to save a text file. The list can keep and merge earlier results. To check only this page, use **Clear** to remove old list entries you no longer need, then extract again.

## Phone extractor

Open **Phone extractor**, check the current webpage and country or region, and extract if needed. The practice page contains **2 numbers** beginning with **+1 202**.

Full international numbers can be recognized with their country code. For local numbers, select the right country or region first. Not every numeric string on a webpage is a phone number. Use **Download all** to save the results.

## Image extractor {#images}

Open **Image extractor**, then refresh the practice page so its images load again. Find the **2 sample illustrations**. On real websites, scroll gradually after entering the tool to reveal images loaded later.

Hover over an image and use its download icon to save it, or choose **Download all** for a batch. The folder setting is a subfolder of the browser download directory, such as **practice-images**. Leave it empty for the default location.

For duplicate names, choose automatic renaming, overwrite, or skip. Use renaming for your first exercise, then check that the saved images open correctly.

The list contains resources observed by the tool and may not include every resource on a website. To put product names, prices, and image URLs on the same table, use [list collection](/en/tutorial/list-pagination).

## If the current page is not recognized

Check that the tool shows the intended target webpage. Refresh that page after installing or updating the extension. Browser settings, extension pages, and app stores are restricted; see [Unsupported page or refresh required](/en/troubleshooting/page-not-supported).
