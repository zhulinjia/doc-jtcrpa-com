# Jiutouchong RPA Agent Help

Jiutouchong RPA Agent is a browser extension that lets AI prepare web tasks from your instructions. Tell AI what you want to do, then start the saved task and check its results. You can run the task again or edit it through the conversation.

In an English-language browser, look for **Jiutouchong Agent — Web Scraping & Automation**. It is the same extension.

## Start here

1. [Introduction](/en/guide/what-is-jtcrpa) — See how a page of books becomes an Excel file, and try it yourself.
2. [Install and sign in](/en/guide/install) — Add the extension to your browser and sign in.
3. [Your first collection](/en/guide/first-task) — Send one request, collect 4 books, and download an Excel file.
4. [Edit a saved workflow](/en/guide/modify-workflow) — Add authors and change the column names.
5. [Use your own webpage](/en/guide/own-page) — Check a small sample from your work before collecting more.

Already installed and signed in? Go straight to [your first collection](/en/guide/first-task). The other pages are available whenever you need them.

## If you get stuck

Start with [Troubleshooting](/en/troubleshooting/) and choose the symptom you see. Even when a task finishes, [check that its results are correct](/en/data/check-results).
