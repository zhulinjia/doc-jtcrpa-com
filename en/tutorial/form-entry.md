# Search and filter before collecting

Tell AI the search term and collect only the matching results. This exercise searches the bookshop for **City**, then collects the matching title and price.

## Send the request

Open the exercise and choose **Compile with AI** on that page:

<PracticeTask lesson="search" />

## Run from the home page

After the task is saved, click **Bookshop playground** at the top to return home. Clear the search and category filters, then use **Manual start** in **Workbench**.

## Check the result

Both the webpage and collected table should contain **City Strolls, ¥45.00**. Check that the result is the searched list, rather than all 4 books from the home page.

If the search term or selected option is wrong, use **Edit** on the original workflow and state what to choose. Restore the agreed starting page before running again.

## Try another condition

Try “Select Travel as the category and collect the matching book titles and prices.” Select the category manually first to see which books should appear, then compare the collected result.
