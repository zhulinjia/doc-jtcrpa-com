# Lists and detail pages

The list contains book titles, but descriptions are on detail pages. Collect the first two books and put each title and its description on the same row.

## Send the request

Open the practice bookshop and choose **Compile with AI** in the extension:

<PracticeTask lesson="detail" />

## Run the task

When the workflow card appears, click **Bookshop playground** at the top of the page to return home. Use **Manual start** in **Workbench**. The task may open details or new tabs; let it finish.

## Match titles and descriptions

Open **Storage → Preview** and check these two results:

| Book | What its description mentions |
| --- | --- |
| Between Mountains and Seas | Journeys and homecomings |
| City Strolls | Walking through city streets |

Each title must share a row with its own description. If they are mismatched, click **Edit** and say “The description for the second book is wrong. Please check.” Run the two-book sample again after saving.

## Use it for work

Replace books with articles, products, or other items and name the details you need. Check two or three records before collecting more. Add your page limit if the list also has pagination.
