# Sign-in, CAPTCHAs, and manual steps

Sign in to the target website normally before collecting. Start from a page where you can see the content you need.

## Before starting

1. Open the target website and sign in yourself.
2. Navigate to the actual list or detail page and wait for the content.
3. Close dialogs that cover it, then open the extension and describe your task.

Keep passwords out of collection requests. Signing in to the Jiutouchong website does not sign you in to other websites.

## Sign-in or verification during a run

If the workflow pauses, read the page and sidebar prompts. Complete sign-in, the CAPTCHA, or another confirmation yourself. Return to the original target page and click **Resume** on the workflow card.

A run that has already failed and ended cannot be resumed. Check its existing results before starting again, particularly if it submits, pays, or sends content.

Try the <a href="/en/practice/scenarios/operations/access.html" target="_blank" rel="noopener noreferrer">manual-step simulation ↗</a> first. It needs no real account and demonstrates only the sequence, not guaranteed support for a real website.

## Repeated verification prompts

End the task, check that the site works manually, and retry a smaller sample. If the issue continues, provide the request, page URL, and [run logs](/en/automation/run-logs). Follow the website verification requirements.
