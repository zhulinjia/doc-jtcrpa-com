# Enable user scripts when prompted

Some tasks show a permission card asking you to allow user scripts. Follow the browser setting instructions on the card; you do not need to write code.

## Follow the permission card

1. Click **Open extension settings** to open the Jiutouchong Agent details page.
2. Enable the user-script setting. Its wording can be **Allow user scripts** or **Allow running user scripts**, depending on the browser.
3. Return to the target webpage and sidebar, then click **Enabled** on the card.

Once the check passes, the card shows **Enabled, continuing**. A follow-up message may appear automatically. Wait for AI to finish.

If an actual workflow run is paused, you may also need **Resume** on its card. Follow the current prompt.

## Cannot find the setting?

Names and locations vary by browser version. Older versions may require Developer mode; follow the specific steps on the card. Firefox does not have the same switch.

If the details page does not open, enter chrome://extensions in Chrome or edge://extensions in Edge and find Jiutouchong Agent.

If the permission is not detected, check the setting for the correct extension, then return and click Enabled again. If the extension has not declared the required permission, update it before retrying.

## What the permission does

It allows the extension to execute AI-generated page actions. Enable it only for an extension you trust, and still check the target content and form entries. Permission alone does not verify the result; continue with [Check your results](/en/data/check-results).
