# Check your results

A completed workflow means its steps ended. Check that the results meet your goal before increasing the number of pages or records.

## Check these four things

| Check | Bookshop example |
| --- | --- |
| Correct scope | The first page has 4 books; the first two pages have 8 different books. |
| Matching values | Between Mountains and Seas costs ¥32.00, rather than another book price. |
| Later content was included | Check Little Maps for the Journey on page 2, or each matching detail description. |
| Which run produced it | Use Collected at and Source page to distinguish older and newer content. |

Compare rows in [Your first collection](/en/guide/first-task) and check page 2 in [Pagination](/en/tutorial/list-pagination). A count alone can hide repeated collection of the same page.

## Formatting may differ

32 and ¥32.00 may represent the same amount. Column names can be changed to English or another language. Check meaning and matching values first. For a required format, see [Filter and format results](/en/data/tidy-results).

Check the full length and leading zeros of order numbers and phone numbers. Open a downloaded Excel file too, to confirm your spreadsheet software displays the intended values.

## Tell AI what is wrong

Click **Edit** on the workflow and describe what you see:

> I asked for the first two pages, but only page 1 was collected. Please check.

You can also say “The second book has the wrong description” or “The price column is empty.” After saving, return to the starting page, run a small sample, and check again.

## Try it yourself

Before running the pagination exercise, work out which books should appear. Check the scope, content, and source together before using the table for your next task.
