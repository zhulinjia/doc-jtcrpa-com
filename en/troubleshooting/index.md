# Start troubleshooting here

Choose the symptom you see. Start with the relevant page below.

| Symptom | Where to look |
| --- | --- |
| Missing icon, or a new installation does not work | [Install and sign in](/en/guide/install) |
| AI is preparing the task, or shows account and permission cards | [While AI prepares your task](/en/guide/during-compile) |
| Empty results or a lot of missing content | [No data or empty results](/en/troubleshooting/empty-result) |
| A run stopped and shows Resume or End | [A run has stopped](/en/troubleshooting/interrupted) |
| The page is unsupported or needs a reload | [Page support](/en/troubleshooting/page-not-supported) |
| Wrong counts, old columns, duplicates, or earlier data | [Check results](/en/data/check-results) and [Format results](/en/data/tidy-results) |
| An exported file will not open, or numbers look wrong | [Export data](/en/data/export) |
| A schedule did not start | [Scheduled tasks](/en/automation/scheduled-task) |
| A long run slows down or the page stops moving | [Keep long runs awake](/en/troubleshooting/anti-sleep) |
| Email did not arrive | [Email notifications](/en/automation/notifications) |
| An unfamiliar message | [Error reference](/en/troubleshooting/error-reference) |

## Record what happened before changing the task

Open **Logs** for the relevant run. Check its last page and whether it was waiting for your help. Previously saved or submitted content may remain; check before retrying forms or outgoing data.

Use **Edit** on the original workflow and describe the symptom, such as “Page 2 is missing. Please check.” You do not need to guess the technical cause.

## Report a problem

Open **Contact Us** at the bottom of the sidebar and provide:

- The request you sent and the webpage URL.
- Expected and actual results, preferably with one example row.
- The time, extension version, and browser name.
- The relevant run log, saved using **Export .log** in [Run logs](/en/automation/run-logs).

Review logs and screenshots for account details, private page content, and keys before sharing. Account passwords are not needed.
