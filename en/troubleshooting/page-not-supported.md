# Unsupported page or refresh required

**This page needs a reload** can usually be handled by refreshing. **This page is not supported** requires switching to a supported webpage.

## This page needs a reload

Tabs opened before an extension installation or update may need to be refreshed. Use **Refresh** on the prompt card or refresh the target webpage manually.

After **This page is working normally again** appears, check whether your request was actually sent. If the message failed to send, send it again as prompted. Wait for any current AI generation to finish before resending.

## This page is not supported

Browser settings, extension management, stores, and the extension own settings and preview pages cannot be collected like ordinary websites.

Switch to a normal website and open the extension there. Try the <a href="/en/practice/index.html" target="_blank" rel="noopener noreferrer">practice bookshop ↗</a> to check the basic setup.

An HTML file opened directly from your computer is also different from a normal website. For Excel or text files, use [Add file](/en/tutorial/upload-table) or [Read local files](/en/data/local-file).

## A normal website still does not work

Check that the extension is enabled and permitted on that website. An organization-managed browser may restrict permissions. Refresh and retry. If it persists, record the full message and the browser and extension versions, then follow [problem reporting](/en/troubleshooting/).
