# 这个网页采集不了

发完需求，对话里却出现一张卡片说当前页面用不了。本篇说清两种卡片，以及为什么有一种**刷新也没用**。

## 先记住一句话

**说「刷新」的就去刷新，说「不支持」的就去换个普通网页。**

两种卡片的标题就差几个字，但处理办法完全相反。

## 一、「当前页面不支持操作」——这类网页天生用不了

卡片原文：

> **当前页面不支持操作**
> 浏览器内部页面、扩展页面、应用商店和本地文件都无法使用采集功能，请切换到普通网页。

指的是这几类地址：

- 浏览器的**设置页**、**扩展管理页**（地址以 `chrome://` 或 `edge://` 开头的那种）
- 浏览器的**应用商店页面**
- **扩展自己的页面**（例如九头虫 Agent 的设置页、数据预览页）
- **本机文件**（地址以 `file://` 开头）

::: warning 刷新没用，等也没用
这一类是浏览器的规定：这些地址压根不允许扩展在里面干活。**刷新一百次也一样。**

办法只有一个：**切到一个普通网页**（地址是 `http` 或 `https` 开头的那种），再发一次需求。
:::

::: tip 一个常见误会
想采集应用商店里的商品信息——**办不到**，商店页面正好属于"不支持"这一格。

要采商品，得打开商品所在的普通网站页面。
:::

## 二、「需要刷新当前网页」——刚装完或刚更新

卡片原文：

> **需要刷新当前网页**
> 插件刚安装或更新，部分功能暂未生效，刷新页面后即可正常使用。

**为什么会这样**：扩展刚装上、或者刚更新过版本，**在那之前就已经开着的网页**还没接上新版本。

**怎么办**：卡片上有个「**刷新**」按钮，点它就行（正在刷新时按钮会变成「刷新中...」）。
它刷新的是**卡片记下的那一页**——所以哪怕你已经切到别的标签页了，刷的也是对的。

刷新完成后，这张卡片会**变成一条提示**：

- 「**当前网页已恢复正常**」
- 「刚才的消息没有发送成功，请再发送一次。」

::: warning 看见这句话，要自己再发一次
刷新**不会**让 AI 自动接着干活。你刚才那条需求**根本没发出去**。

在**那条提示的下方**有个重新发送的小按钮（环形箭头图标），点它把这一轮再发一次即可——
你的需求一直都在，没丢。
:::

## 三、怎么区分这两种卡

用户最容易搞混的就是这里：

| 卡片标题 | 刷新有用吗 | 你该做什么 |
| :--- | :--- | :--- |
| **需要刷新当前网页** | 有用 | 点卡片上的「刷新」 |
| **当前页面不支持操作** | **没用，刷新也不会变** | 换到一个普通网页 |

前者是**临时的**（扩展刚更新），后者是**这类地址本来就不允许**。所以只有前者会给你刷新按钮。

## 四、这张卡是"长在消息下面"的

它出现在**对话里你那次发送的位置**，不是在页头，也不是在侧边栏顶部。

因为它的意思正是：「**你刚才那一轮我没发出去**，原因是页面这样」。所以：

- 看到这张卡，说明 **AI 那一轮什么都没干**（不是它偷懒）。
- 你的需求还留在对话里，**不会丢**。

> 页面正在加载、或者当前没有可用的标签页时，它**不下结论、也不会弹卡**——
> 稍等一下再发即可。

## 五、提取页面上也会看到同样的话

「**邮箱提取**」「**电话提取**」这些页面上，如果当前页读不到内容，结果区会给出**同样的两句提示**
（少了按钮，样式是一条虚线框）。

**你要做的**：自己按 F5 刷新那个网页，或者换到普通网页，再点一次提取。
