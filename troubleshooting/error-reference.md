# 提示信息对照表

把界面上最常出现的提示按原话列一遍，每条配「什么意思 + 怎么办」。

**用法**：把界面上那句话原样对照着找。找不到就往下翻到最后一节。

## 一、AI 诊断标签（13 个）

出现在**网页右下角的轻提示**和执行日志里，长得像「**AI 诊断：需要登录**」。一共就这 13 个：

| 标签 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| **需要登录** | 目标网站要登录才能看内容 | 先在浏览器里登录，再点「恢复」 |
| **需要过验证码** | 页面弹了验证码 | 手动过一次，然后点「恢复」 |
| **站点已改版** | 网站改版了，旧工作流失效 | 回「AI 编译生成」把需求再说一遍 |
| **当前页不是目标页** | 跑到别的页面上去了 | 点「恢复」让它自己找回来；不行就结束重跑 |
| **未能采集到数据** | 页面上没找到要采的内容 | 见[采不到数据怎么办](/troubleshooting/empty-result) |
| **页面不存在** | 网址打不开（被删或输错了） | 检查网址 |
| **页面未就绪** | 页面还在加载 | 等它加载完再点「恢复」，或在需求里加等待 |
| **权限未开启** | 多半是「允许用户脚本」没开 | 见[自定义脚本](/advanced/user-script) |
| **页面不可用** | 目标页被关了，或者切不过去 | 把那个页面找回来，再点「恢复」 |
| **保存数据失败** | 数据没能存下来 | 重跑一次；反复出现就把日志发给我们 |
| **工作流配置有误** | 工作流本身有问题 | 重新生成一个工作流 |
| **引擎执行异常** | 我们自己出错了 | **这是我们的问题**，把日志发给我们 |
| **诊断未返回结论** | 它自己也没判断出来 | **这是我们的问题**，把日志发给我们 |

## 二、运行状态与卡片上的按钮

| 提示 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| 「工作流已完成」 | 跑完了，成功 | 去「数据存储」看结果 |
| 「工作流执行失败」 | 跑完了，失败 | **具体原因在日志里**，见[执行日志](/automation/run-logs) |
| 「选择器已自愈，正在继续执行」 | 页面结构变了，它自己换了条路，**正常运行** | 不用管 |
| 「当前挂起处是引擎内部步骤，没有可跳过的步骤——请用「恢复」继续」 | 卡住的位置没法单独跳过 | 用「恢复」或「结束」 |
| 「恢复未重派：运行页已关闭」 | 那个采集页面被关了，本次运行已结束 | 重新打开目标网页，再重新启动工作流 |
| 「恢复未重派：运行页未响应」 | 那个网页卡死了 | 刷新那个标签页再点「恢复」 |
| 「恢复未重派：运行页正在加载」 | 那个网页还在加载 | 稍等一会儿再点 |
| 「上次会话的运行在浏览器启动时被中断」 | 浏览器/电脑重启打断了那次运行，它不会自己接着跑 | 重新点一次启动 |
| 「运行页被浏览器休眠（后台标签页），心跳自检本拍跳过」 | 页面被浏览器休眠了，**采出来可能是空的** | 见[长时间采集防休眠](/troubleshooting/anti-sleep) |
| 「等待元素出现超时（10000ms）」 | 等到上限，要等的那块内容还没出现，这一步被跳过 | 见[等页面加载完成再采集](/tutorial/wait-page)：把上限调大，或先确认页面能正常打开 |
| 「等待元素消失超时（10000ms）」 | 要等它消失的东西一直没消失（转圈、遮罩、弹窗卡住） | 同上；遮罩一直不消失通常是页面出错，刷新重跑 |
| 「「名称」启动失败：未找到活动标签页，请先打开要采集的页面」 | 没有可用的标签页 | 先打开要采集的那个网页再启动 |
| 「未找到要执行采集的页面，请重试」 | 用「右键执行」时页面找不到了 | 在目标网页上重新右键一次 |
| 「该工作流已不存在，右键菜单已取消」 | 挂在右键上的工作流被删了 | 重新选一个工作流设为右键执行 |
| 「运行「名称」已挂起，请到侧栏查看」 | 系统通知版的挂起提醒 | 见[运行中断了怎么办](/troubleshooting/interrupted) |

## 三、账号与会员

运行时发现权限不够，会给出这四种说法之一，并配一个按钮：

| 提示 | 按钮 | 去做什么 |
| :--- | :--- | :--- |
| 「请先登录官网账号」 | 去登录 | 登录账号 |
| 「该功能需要开通会员套餐」 | 去开通 | 开通会员 |
| 「会员套餐已到期，请续费后使用」 | 去续费 | 续费 |
| 「本次 N 条超出当前档位上限（M 条），升级会员可提高额度」 | 去升级 | 升级档位，或分批下载 |

对话里另外还有三张卡片，按卡片上的按钮走就行：

| 卡片标题 | 按钮 |
| :--- | :--- |
| 当前 AI 模型还没有配置 API Key | 去配置 |
| 需要登录官网账号 | 去登录 |
| 额度不足 | 去充值 |

三张卡片上的按钮点一下就会带你过去，不用自己去菜单里翻。

## 四、导入导出

| 提示 | 怎么办 |
| :--- | :--- |
| 「导入失败：无法读取该文件」 | 文件可能损坏或选错了，重新选一次 |
| 「导入失败：文件不是有效的 JSON」 | 选错文件了，要选从本扩展导出的文件 |
| 「导入失败：第 N 条不是任务包（若这是工作流文件，请到工作流列表导入）」 | **选错了地方**：这是工作流文件，去工作流列表导入 |
| 「导入失败：第 N 条不是有效的工作流」 | 文件内容对不上，重新导出一份 |
| 「导入失败：第 N 条的任务包内容不合法」 | 同上 |
| 「文件中没有可导入的工作流」 | 这份文件里没有工作流 |
| 「文件中没有可导入的任务」 | 这份文件里没有定时任务 |
| 「工作流已不存在，无法下载」 | 这条任务引用的工作流被删了，无法导出 |

详见[导入导出与分享工作流](/advanced/import-export)。

## 五、飞书

| 提示 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| 「检查网络后重试；处在代理环境里的话，确认 open.feishu.cn 走得通」 | 网络不通 | 按它说的查网络或代理 |
| 「这是知识库里的表格，暂不支持」 | 你的表格在飞书知识库里 | 按下面那条照做 |
| 「知识库里的表格拿不到所需的标识。请在飞书里打开它，点右上角「···」→「···更多」→「在浏览器中打开」，再复制那一份链接」 | 换成普通链接就行 | 照做，然后把新链接填回来 |
| 「飞书写入中断：已送出 N 条，这一批失败——…」 | 前面 N 条写进去了，后面停了 | 修好原因再跑；已写入的会重复，注意核对 |
| 「飞书写入未发出：字段「某某」不可写（公式、查找引用、自动编号这类系统列，或我们还不支持的类型）。可写的字段有：…」 | 你选的列飞书不让写 | 换成它列出来的那些字段 |

### 读取飞书表格时

读取和写入用的是同一套应用凭据，上面那张表里的大部分说法读取时也会出现。
另外几句是读取特有的：

| 提示 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| 「飞书还没有配置应用凭据，这一步没有发出。请打开扩展设置里的「飞书多维表格」，填入 App ID 与 App Secret」 | 本机还没配飞书应用 | 先去配置页填 App ID 和 App Secret，见[读取飞书多维表格](/data/feishu-read) |
| 「表格链接不完整」 | 链接少了表格标识那一段（多半是从别处粘了一半） | 在飞书里打开那张表，从地址栏重新复制完整链接 |
| 「知识库里的表格暂不支持」 | 表在飞书知识库里 | 点右上角「···」→「···更多」→「在浏览器中打开」，复制那一份链接 |
| 「这个应用还没有被允许访问这张表。请在飞书里打开它 →「···」→「···更多」→「添加文档应用」，选中你的应用」 | 应用没加进这张表 | 照它说的把应用加进去 |

读到 0 条**不算报错**：表是空的，日志会写「飞书读取：… 里一条记录都没有，已把空数组写进变量…」。
正常读完则会写「飞书读取：从 … 读到 N 条记录…」，用这句对一下条数。

详见[上传到飞书多维表格](/data/feishu)、[读取飞书多维表格](/data/feishu-read)。

## 六、上传表格与读取本地文件

### 上传表格时卡片上直接报错

选完文件、还没发送，卡片上就会写原因，这时改就是了：

| 提示 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| 「仅支持 Excel、CSV、JSON 和 TXT 文件」 | 选的文件类型不支持 | 另存为这几种格式再选 |
| 「无法识别文件编码（不是 UTF-8、GBK/ANSI 或带 BOM 的 UTF-16）」 | 编码太特殊 | 用表格软件另存为 CSV（UTF-8） |
| 「文件不是有效的 JSON，请检查后重试」 | JSON 有语法错误 | 检查 JSON，或改成 CSV |
| 「文件解析失败，请检查文件内容」 | 表格损坏，或扩展名和实际内容对不上 | 用 Excel 打开确认能正常显示，再另存一份 |
| 「数据保存失败，请重试」 | 本地存储没写进去 | 稍后重试；反复出现就把日志发给我们 |

### 运行中与上传表格有关的

| 提示 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| 「数据集「…」在运行中已更新，请结束本次运行后重新运行」 | 跑到一半时替换了这个文件 | 结束本次运行，检查已采集的数据，再重新运行 |

### 读取本地文件

| 提示 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| 卡片「需要开启「允许访问文件网址」」 | 还没给扩展读磁盘的权限 | 点「去开启权限」→ 打开那个开关 → 回侧边栏点「已开启」，见[读取本地文件](/data/local-file) |
| 「读取本地文件失败：路径不是有效的绝对路径…」 | 写成了相对路径，或只写到文件夹 | 换成完整路径，写到具体文件 |
| 「读取本地文件失败：文件不存在、被占用或无法访问」 | 文件被挪走、删掉，或正被别的程序占用 | 确认路径和文件状态，关掉占用它的软件再跑 |
| 「读取本地文件失败：不支持的文件格式，只支持 .txt / .json / .csv / .xlsx / .xls」 | 文件类型不支持 | 另存为支持的格式 |
| 「当前浏览器不支持读取本地文件，请改用其他方式获取数据」 | 用的是 Firefox | 改用[上传表格，按清单采集](/tutorial/upload-table) |

完整的报错清单在[读取本地文件](/data/local-file)那一篇的第四节。

## 七、定时任务

定时到点却没跑时，会收到一条标题为「**定时任务未执行**」的系统通知，正文是「任务名：原因」。

| 提示里的原因 | 怎么办 |
| :--- | :--- |
| 「请先登录官网账号」/「该功能需要开通会员套餐」/「会员套餐已到期，请续费后使用」 | 见上面「账号与会员」那一节 |
| 「无法打开任务页面」 | 任务里的目标网址打不开，检查网址 |
| 「任务不存在」 | 这个任务已经被删了 |
| 「任务未配置目标网址」 | 编辑任务，补上目标网址再保存 |
| 「执行体缺失（包装工作流不存在），请编辑任务后重新保存」 | 按它说的：编辑任务再保存一次 |

::: tip 停用的任务点「立即执行」照样会跑
任务卡上的开关只管**闹钟还响不响**，不管人手动点的那一下。
:::

详见[定时任务](/automation/scheduled-task)。

## 八、批量下载图片

批量存图时会让你先选一个「重复文件怎么办」，这三个选项的意思是：

| 选项 | 意思 |
| :--- | :--- |
| 「冲突时自动重命名」 | 同名文件自动加后缀，两个都留 |
| 「覆盖已有文件」 | 用新的盖掉旧的 |
| 「已存在或进行中则跳过」 | 已经有的不再下载，省时间 |

详见[邮箱 / 电话 / 图片提取](/tools/extract-tools)。

## 九、一句话总结

1. **看到卡片，就按卡片上的按钮走。**
2. **看不到卡片，就去执行日志里找那一句原话。**
3. 两条都做了还不行：**点「导出 .log」把日志发给我们**。

发之前提醒一句：**日志里可能有你的页面内容和账号相关信息，发之前先看一眼**。
