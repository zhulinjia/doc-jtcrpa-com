# 提示信息对照表

按你看到的提示找处理方法。如果出现提示卡片，优先按卡片上的说明和按钮操作。

## 准备任务时

| 提示 | 下一步 |
| :--- | :--- |
| 需要登录官网账号 | 点击「去登录」，完成后返回目标网页 |
| 当前 AI 模型还没有配置 API Key | 点击「去配置」，或在对话区选择有可用额度的服务 |
| 额度不足 | 检查所选服务与额度，见[AI 配置](/settings/ai-model) |
| 需要开启「允许用户脚本」 | 按[权限步骤](/advanced/user-script)开启，再回来点「已开启」 |
| 需要开启「允许访问文件网址」 | 只在需要读电脑文件时，按[本地文件说明](/data/local-file)处理 |
| 需要刷新当前网页 | 刷新目标页，按提示重新发送未发出的需求 |
| 当前页面不支持操作 | 切到普通网页，见[页面支持范围](/troubleshooting/page-not-supported) |

## 运行时的诊断标签

以下标签说明遇到了什么；是否仍可恢复，要结合卡片按钮和日志状态判断。

| 标签 | 可以先做什么 |
| :--- | :--- |
| 需要登录 / 需要过验证码 | 在目标页手动处理；仍挂起时点「恢复」 |
| 当前页不是目标页 | 检查实际网页和工作流用途，按提示回正确页面 |
| 未能采集到数据 | [检查页面与结果](/troubleshooting/empty-result) |
| 站点已改版 | 从原工作流「修改」进入，让 AI 查看新页面 |
| 页面不存在 / 页面不可用 | 检查网址、网络及标签页是否仍开着 |
| 页面未就绪 | 等目标内容出现，必要时[修改等待方式](/tutorial/wait-page) |
| 权限未开启 | 看具体缺少哪项权限，按对应卡片开启 |
| 保存数据失败 | 保留日志，检查现有结果；持续出现时反馈 |
| 工作流配置有误 | 把完整提示告诉 AI，修改后用少量数据验证 |
| 引擎执行异常 / 诊断未返回结论 | 导出日志，带上实际现象反馈 |

## 数据、任务与文件

| 提示或现象 | 下一步 |
| :--- | :--- |
| 工作流已完成，但条数不对 | [检查结果](/data/check-results)，包括历史数据和被跳过的内容 |
| 等待内容出现或消失超时 | 确认网页能正常显示，再让 AI 检查等待目标；不代表一定已跳过 |
| 运行页已关闭 | 检查本次是否结束，确认已有结果后再启动 |
| 工作流已删除 | 编辑定时任务，关联仍然存在的工作流 |
| 执行体缺失，要求编辑后保存 | 打开该任务，核对工作流后重新保存 |
| 下载超出当前档位上限 | 核对数据总条数和套餐权限，见[导出数据](/data/export) |
| 导入失败：不是任务包 | 可能选错入口，工作流文件到「主工作台」导入 |
| 上传文件解析失败或类型不支持 | 用 Excel 打开检查，另存为支持的格式再上传 |
| 数据集在运行中已更新 | 不要边跑边替换文件，检查结果后结束并重新运行 |

飞书权限、空表和部分写入问题，分别见[写入飞书](/data/feishu)与[读取飞书](/data/feishu-read)。邮件提交但未收到，见[邮件提醒](/automation/notifications)。

找不到对应提示时，保留完整原文，按[反馈说明](/troubleshooting/)提供日志。无需先把技术词翻译成别的说法。
