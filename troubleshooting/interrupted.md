# 运行中断了怎么办

先看工作流卡片上有什么按钮。**还有「恢复」通常表示在等待处理；「手动启动」重新出现，表示这次运行已经结束。**

## 有「恢复」：先处理网页

查看网页上的提示，完成登录、验证码、权限设置，或关闭挡住内容的弹窗。回到正确页面后，在原工作流卡片点击「**恢复**」。自己点了「中断」暂停时，也可以这样继续。

如果工作流要求你先完成一项人工操作，按它给出的说明处理，再恢复。权限提示见[开启用户脚本](/advanced/user-script)。

不知道该做什么时，先打开「**日志**」看挂起原因。拿不准不要随便点「跳过」：它会放弃当前整个步骤，可能漏数据，也可能影响后面的填写或提交。

## 已经结束：先检查，再重新启动

打开[执行日志](/automation/run-logs)确认本次状态和停止位置。已经采集的数据可能仍在表里；已经提交或发送的内容也可能已经到达对方。

浏览器或电脑重启后，先前运行不会自动从停下处继续。确认已完成的部分，再打开目标页重新启动。定时任务也要检查运行记录，需要补跑时使用「立即执行」。

## 点击恢复仍无进展

| 提示或现象 | 下一步 |
| :--- | :--- |
| 运行页正在加载 | 等网页加载完，再尝试恢复 |
| 运行页未响应 | 检查页面能否正常操作；必要时刷新后按提示处理 |
| 运行页已关闭 | 本次可能已结束，重新打开目标页，检查结果后重启任务 |
| 长时间没有新进度 | 查看日志是否仍更新，并检查[休眠设置](/troubleshooting/anti-sleep) |

需要停止本次运行时点击「**结束**」。它会直接终止，之后要重新启动。四个控制按钮的区别见[启动、中断与结束](/automation/start-stop)。
