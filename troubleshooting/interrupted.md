# 运行中断了怎么办

跑到一半停了。本篇先帮你分清它是**在等你**、还是**真出事了**，再对症处理。

::: tip 一句话判断
**卡片上还有按钮 = 它在等你；卡片回到空闲、按钮都没了 = 这次运行已经收了。**
:::

## 一、先分清两种「停」

| 你看到的 | 是什么 | 该怎么办 |
| :--- | :--- | :--- |
| 卡片上有「恢复」「跳过」「结束」这些按钮 | **挂起**——它停下来等你 | 处理完点「恢复」 |
| 卡片回到空闲，启动键又能点了 | **结束**——这次运行已经收了 | 失败原因去执行日志里看 |

**挂起是能接着跑的**，进度还在。结束就接不回来了。

## 二、挂起有三种，看页面上的提示分辨

同样是「停下来了」，原因不一样，提示也不一样。

### 一、页面有障碍，它处理不了

目标网页的右下角会弹出一张小卡片：

- 标题：**「运行遇到障碍，需要处理」**
- 下面一枚标签：**「AI 诊断：xxx」**
- 正文写着它认为出了什么事

同时：

- 侧边栏会弹一句「运行已挂起：处理完页面障碍后，在运行卡点「恢复」或「结束」（AI 诊断：xxx）」
- 浏览器还会发一条系统通知：「**运行「工作流名」已挂起，请到侧栏查看**」

**你要做的**：切到那个网页，把障碍处理掉（登录、过验证码、关掉挡路弹窗），再回来点「恢复」。

那枚标签上的词是什么意思，查[提示信息对照表](/troubleshooting/error-reference)。

### 二、工作流里本来就有一处「暂停」

有些工作流会**故意**在中间停一下，等你先在别处操作完再往下走。

- 页面卡片标题：**「运行已暂停，等待你处理」**，正文写着它想让你做什么
- 执行日志里对应的一行是「运行已暂停，等待人工处理：…」

**你要做的**：照它说的做完，回侧边栏点「恢复」。

### 三、你自己点了「中断」

这是最安静的一种：**什么提示都不弹**，卡片只是变成「已挂起：」。

**你要做的**：想继续就点「恢复」。

::: tip 第三种和前面两种怎么分
前两种是**它主动来找你**——目标网页上看得见提示；第三种是你叫停的，所以安安静静。
:::

## 三、挂起时你手上有哪些按钮

| 按钮 | 作用 |
| :--- | :--- |
| **恢复** | 从停下的地方接着跑 |
| **跳过** | 丢掉当前这一步继续。**会先弹确认框**，这一步的数据就没采到 |
| **结束** | 中止这次运行，接不回来 |

断得细一点看[启动、中断与结束](/automation/start-stop)。

跳过之后，日志里会留下痕迹：那一行带「**已跳过**」这枚标签，写着
「已跳过「某某」节点，本步未执行」，或者「「某某」失败已跳过，本步未执行」。

> 偶尔会看到「**当前挂起处是引擎内部步骤，没有可跳过的步骤——请用「恢复」继续**」——
> 意思是卡住的位置没法单独跳过，**不是按钮坏了**。这时只剩恢复和结束两条路。

## 四、跑了很久又像卡住不动

先别急着结束，先翻日志看它是不是还在动：

- 日志里如果**一直在出现新的「累计执行 N 步…」**，说明它还活着，只是在慢。
- 如果**很久没有新行**，多半是页面被浏览器休眠了——见[长时间采集防休眠](/troubleshooting/anti-sleep)。

## 五、浏览器重启或电脑重启之后

重启会**打断正在跑的运行**，而且这次运行**不会自己接着跑**——它会被直接标成结束。

你能看到的痕迹是：那次运行在[执行日志](/automation/run-logs)里状态是「**已失败**」，
其中有一行写着「**上次会话的运行在浏览器启动时被中断**」。

**想接着采，重新点一次启动就行**，不用做别的。

::: warning 定时任务不一样
定时任务到点会**照计划重新触发**，不受这次重启影响。见[定时任务](/automation/scheduled-task)。
:::

## 六、点了「恢复」却像没反应

它有三种明确的说法，各对着一个原因——都是**没恢复成功**，运行还停在那儿：

| 提示 | 原因 | 怎么办 |
| :--- | :--- | :--- |
| 「恢复未重派：运行页已关闭」 | 那个采集页面被关掉了 | 重新打开那个网页，再点一次「恢复」 |
| 「恢复未重派：运行页未响应」 | 那个网页卡死了 | 刷新那个标签页，再点一次「恢复」 |
| 「恢复未重派：运行页正在加载」 | 那个网页还在加载 | 稍等一会儿再点 |

## 七、怎么少被打断

- **别让页面出障碍**：开始前先登录好，把弹窗关掉。
- **别最小化窗口**：页面被浏览器休眠也会让运行停住，而且不一定报错。
  见[长时间采集防休眠](/troubleshooting/anti-sleep)。
- **需求里补一句等待**：加载慢的站点，写「每次翻页后等待 3 秒」。
