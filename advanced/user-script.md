# 自定义脚本

个别网页用常规办法取不到数据时，AI 会写一小段脚本去取。**你不用写任何代码**，
部分浏览器需要先给扩展开一个开关。本篇讲怎么处理提示、运行时会看到什么。

## 一、什么时候会用到它

**由 AI 在编译时自己判断，你通常不用主动要。**

典型场景是页面上那个数字是**页面上算出来的**，网页原文里根本没有——常规方式读不到。
这时候 AI 会先来问你要权限，对话里会出现一张卡片。

**你要配合的只有一件事：把要的结果说清楚。** 例如说「把页面上那个总价按千分位格式取出来」，
剩下的是它的事。

## 二、按提示开权限

对话里出现标题为「**需要开启「允许用户脚本」**」的卡片时，**卡片上列着步骤，照着点**：

1. **点「去开启权限」** —— 它会打开本扩展在浏览器里的详情页。
2. **在详情页里找到「允许用户脚本」，打开它。**
3. **回到侧边栏，点「已开启」。**

::: tip 浏览器里它叫「九头虫 Agent」
扩展详情页上的名字是「**九头虫 Agent**」——**就是它**，别找错了。

两个按钮都能用：**「去开启权限」**打开详情页，**「已开启」**是你开好开关后回来点的。

### 点不动、或者点了说没检测到

| 卡片上冒出这句 | 什么意思 | 怎么办 |
| :--- | :--- | :--- |
| **浏览器不让扩展自己打开这个页面，请手动打开 chrome://extensions 找到本扩展** | 浏览器不允许扩展自己跳转 | 自己在地址栏里打开扩展管理页，找到「九头虫 Agent」，一样能在那里开开关 |
| **还没检测到「允许用户脚本」，确认开关已打开再点一次** | 开关其实还没开上 | 确认开关真的打开了，再点一次「已开启」 |
| **本扩展未声明「用户脚本」权限，需要更新扩展——不是浏览器开关的问题** | **不是开关的事** | 把扩展更新到最新版，或者重新安装一次 |

如果提示扩展未声明权限，卡片没有「去开启权限」按钮，需要更新或重装扩展。开关未检测到时，请核对开关后再次点击「已开启」。

::: tip 扩展管理页在哪
自己在地址栏输入：Chrome 是 `chrome://extensions`，Edge 是 `edge://extensions`，回车就到。
（这也是[安装与首次使用](/guide/install)里打开开发者模式的那个页面。）
:::

**浏览器版本不同，步骤也不同**：如果卡片提示打开「开发者模式」，请按卡片操作；有的版本不会提供单独的「允许用户脚本」开关。Firefox 使用这一功能时没有这项开关。

### 开好之后会看到什么

检测通过了，你会看到两样东西：

- 对话里多出一条**你自己发的消息**：「**已开启用户脚本权限，继续**」——
  这句是**扩展替你发的**，不是你打的，别被自己吓一跳。
- 卡片收成一行「**已开启，继续执行**」，编译接着往下走。

## 三、跑的时候，日志里会写什么

这一步在[执行日志](/automation/run-logs)里的「结果」栏，会写这几种之一：

| 日志里写的 | 意思 |
| :--- | :--- |
| **脚本返回：某某值** | 正常，它取到东西了 |
| **脚本执行完成（无返回值）** | 跑了，但没给出结果。多半是这一页确实没东西可取 |
| **用户脚本执行失败** | 脚本本身没跑通 |

::: tip 这一步的标签是英文的 userScript
日志里这一行的**短标签会是英文 `userScript`**——界面没给它配中文名，不是出错。

它旁边的描述是 AI 写的，写的是这一步在干什么（比如「提取总价」）。
:::

## 四、这一步失败会怎样

具体处理取决于失败原因和工作流：

- **有些情况会跳过这一步，继续往后跑。** 日志里那一行会带「**已跳过**」标签，
  写着「已跳过「某某」节点，本步未执行」。**后面的步骤可能因此受影响**，结果要自己核对一下。
- **如果它判断这是"该你出手"的事**——最常见的就是开关被关掉了——运行会**挂起**等你。
  网页上会提示「**未开启「允许用户脚本」，脚本注入不了**」，
  把开关打开，再回运行卡点「恢复」继续。见[运行中断了怎么办](/troubleshooting/interrupted)。
- **连续跳过好几步**时，它会停下来问你，而不是一路跳到底。

## 五、关于安全，说几句实在的

- 脚本是 AI **根据你的需求现场生成**的，**只在你自己的电脑上、只在你当时打开的那个网页里**运行。
- 打开这个开关，等于**允许扩展在你访问的网页上执行脚本**。不开也不影响别的事——
  **绝大多数采集根本用不到它**，只有真碰到上面那种取不到的情况才会来问你。
- 这个功能**不需要会员**，只跟浏览器这个开关有关。
