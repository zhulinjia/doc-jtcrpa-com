# 备份、迁移与分享工作流

好用的工作流可以存到电脑，换浏览器或分享给同事时再导入。**采集结果要另外下载，工作流文件不等于数据备份。**

## 先选你要保存什么

| 想保存的内容 | 导出入口 | 以后从哪里导入 |
| :--- | :--- | :--- |
| 已准备好的操作步骤 | 主工作台卡片的「更多操作 → 下载工作流（JSON）」 | 主工作台的「导入工作流」 |
| 定时任务、网址清单和关联工作流 | 定时任务卡片的「更多操作 → 下载定时任务（JSON）」 | 定时任务的「导入任务」 |
| 已采集的数据 | 数据存储中结果的「下载」 | 表格可留作备份，需要处理时重新上传 |

不同页面导出的文件，请回对应页面导入。下载的工作流和任务包保持原文件即可，不需要打开修改内容。

## 换电脑前做这几步

1. 在「**数据存储**」把需要的结果下载为 Excel，打开核对。
2. 在「**主工作台**」找到要带走的工作流，点击「**更多操作 → 下载工作流（JSON）**」。
3. 有定时任务时，点击该卡片的「**更多操作 → 下载定时任务（JSON）**」保存任务包；准备导入后先手动测试的，可以先关闭定时开关再导出。
4. 在新浏览器安装扩展，从对应入口导入。检查任务开关，避免尚未试跑就到点执行。
5. 重新登录目标网站，按需要配置 AI、飞书和本地文件，先用少量数据试跑，再开启定时。

浏览器登录状态、AI 密钥、飞书应用配置和电脑上的文件，不会作为独立配置自动迁过去。工作流调用了其他工作流时，也要一起核对，见[组合已有工作流](/tutorial/workflow-invocation)。

## 导入后出现两张同名卡片

导入会新增，**不会覆盖同名工作流，也不会自动去重**。同一文件导入两次，可能看到两张一样的卡片。

更新共享规则时，先保留旧的，导入新版并用少量数据验证。确认新版符合要求后，再决定是否删除旧版。删除工作流前，还要检查有没有定时任务或其他工作流正在使用它。

## 分享前检查内容

工作流可能包含目标网址、固定填写的文字和你在需求里提供的业务信息。发给同事前先核对，尤其是内网链接、固定账号和验证信息。接收方使用自己的浏览器登录状态，收到文件后仍要试跑。

导入失败时，先确认入口和文件是否选对，再请提供方重新导出原文件。不要为了修复导入错误，直接修改看不懂的文件内容。
