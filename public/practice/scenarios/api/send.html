采集当前页面的练习订单，金额保留 ¥ 符号。用 HTTP 请求以 POST 方式按 JSON 发送到 https://httpbin.org/post。把返回结果中 json 里的订单编号、商品和金额保存到数据存储；如果发送失败，暂停并提示我。

工作流保存后，在「主工作台」点击「手动启动」。完成后打开「数据存储」，核对返回的订单编号、商品和金额是否与下方一致。

注意：此练习会真实发送到第三方测试服务，只能使用页面上的虚构订单，请不要发送个人信息或真实业务数据。
