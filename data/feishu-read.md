# 读取飞书多维表格

如果你的数据已经在飞书多维表格里——比如一份商品链接表、一份待核对的名单——可以让 AI
直接把整张表读进来，再按你说的方式逐条处理。不用先导出成文件。

::: tip 和「写入飞书」共用一套配置
读取和写入用的是同一个飞书应用、同一组 App ID / App Secret。
没配过的话，先按[写入飞书多维表格](/data/feishu)完成配置；配过就直接往下看。
:::

## 一、先确认这张表允许你的应用访问

和写入一样，应用必须被加到这张表上：

1. 在飞书里打开那张多维表格。
2. 点右上角「**···**」→「**··· 更多**」→「**添加文档应用**」。
3. 选中你配置的那个应用，确认。

没做这一步，读取时会提示「这个应用还没有被允许访问这张表」。

::: warning 知识库里的表不行
如果表格在飞书知识库里，先点「**···**」→「**··· 更多**」→「**在浏览器中打开**」，
用新标签页里那份普通链接。知识库地址读不出表格标识。
:::

## 二、在需求里粘链接

把表格链接完整粘进采集需求，再说清楚要做什么：

> 读取这张飞书表格：`https://xxx.feishu.cn/base/xxxx?table=tblxxxx`
> 打开里面每个商品链接，采集标题和价格。

> 读取这张表，统计每个城市的订单数，不用打开链接。

链接**从浏览器地址栏整段复制**，别漏掉末尾的表格参数；漏了会提示「表格链接不完整」。

## 三、运行时会看到什么

- AI 会**一次性读完整张表**，不需要你分页，也不用写循环次数。
- 读到的列名就是飞书表里的列名；后面按列名说需求即可。
- 执行日志会写读到了多少：

  > 飞书读取：从 … 读到 120 条记录…

- **空表也算成功**：

  > 飞书读取：… 里一条记录都没有…

  这时下游看到的是「0 条」，不会把整次运行判成失败。
- **多行文本**会拼成一段文字；**超链接列**取的是链接地址，不是显示出来的文字。
- 表很大时读取会久一点。运行期间保持浏览器窗口可见，别让标签页被休眠。

## 四、常见报错

### 编译时出现「本机还没配置飞书应用凭据，数据写不进飞书」卡片

读取用的也是这套凭据，照卡片走就行：

1. 点「**去配置**」，打开「飞书多维表格」配置页。
2. 填好 App ID 与 App Secret，点「测试连接」验证。
3. 回到侧边栏点「**已配置**」。扩展会替你发一句「已配置好飞书应用凭据，继续」。

点「已配置」后如果提示「还没检测到飞书应用凭据」，确认两个值都填好了再点一次。

### 运行时日志里的原话

| 日志里的原话                                                                                                         | 原因                                   | 怎么办                                                       |
| :------------------------------------------------------------------------------------------------------------------- | :------------------------------------- | :----------------------------------------------------------- |
| 「飞书还没有配置应用凭据，这一步没有发出。请打开扩展设置里的「飞书多维表格」，填入 App ID 与 App Secret」             | 凭据根本没填                           | 按上一节配好再跑                                             |
| 「这个应用还没有被允许访问这张表…请…「添加文档应用」…」                                                             | 漏了把应用加到这张表上                 | 在飞书里打开这张表，按第一节第 2 步加上应用                   |
| 「应用缺少多维表格权限…请到飞书开放平台开通权限并发布一个新版本，没发布不生效」                                       | 权限没开，或开了但没发布版本           | 开通多维表格权限，并在「版本管理与发布」发布一个新版本       |
| 「表格链接不完整」                                                                                                   | 链接只复制了一部分                     | 回到飞书，从地址栏整段重新复制                               |
| 「知识库里的表格暂不支持」                                                                                           | 表格在知识库里                         | 用「在浏览器中打开」后的普通链接                             |
| 「没找到这张表或这个应用…」                                                                                           | 链接或 App ID 抄错，或表已删除         | 核对链接是不是最新的一份，以及 App ID                       |
| 「请求太频繁，被飞书限流了…」                                                                                         | 短时间内请求太多                       | 等一会儿再跑                                                 |
| 「连不上飞书…」                                                                                                       | 网络不通                               | 检查网络；用了代理的话确认飞书开放平台走得通                 |

::: tip 配置页的「测试连接」是写给写入的
配置页上的说明和「测试连接」都是按**写入**写的，它只验证凭据和某张表能不能访问，
不会读取数据。读取用同一套凭据，不受影响。
:::
