# 数据存储与数据预览

工作流保存到本地的数据可以在「数据存储」中查看和管理。本篇介绍如何查看、下载和删除数据集；读取本地文件或发送到其他系统的数据不一定会出现在这里。

## 进入数据管理中心

点击侧边栏右侧图标栏里的**数据库形状图标**（鼠标停上去会显示「数据存储」），进入数据列表视图。

每个独立的数据采集任务对应一张**独立的数据集卡片**。若尚未执行过任何任务，界面将显示「暂无采集记录」。

![「数据存储」列表：每张卡片左边是网站图标，上面是工作流名称和数据集标识，中间是「7 个字段」「299 条数据」两个标签，底部是更新时间、下载、上传飞书和垃圾桶图标](/images/storage-list.png)

## 数据集卡片信息解析

每张卡片记录了该数据集的核心元数据：

| 元素位置           | 展示内容                       | 说明                                                |
| :----------------- | :----------------------------- | :-------------------------------------------------- |
| **网站图标**       | 目标站点的 Favicon 图标        | 鼠标悬停可查看采集来源的网页基础域名。              |
| **加粗大标题**     | **工作流名称**                 | 点击可在独立标签页打开全屏数据预览。                |
| **等宽小字**       | **数据集系统标识**             | 系统分配的底层唯一 ID，供高级调用或排查时精确定位。 |
| **灰色小字**       | **最近一次采集的网页标题**     | 如「百度热搜」，用来区分同名的不同数据来源。        |
| **字段与条数标签** | 如「5 个字段」「1,200 条数据」 | 统计当前数据集累计沉淀的行列规模。                  |
| **更新时间**       | 最后一次采集的时间戳           | 方便识别最新采集的批次（重复采到相同内容也会刷新）。 |

::: tip 从文件导入的数据集，标题是文件名
在对话里直接上传的 Excel / CSV / JSON / TXT 文件，也会作为一份数据集出现在这里。
它和采集来的数据集区别有三处：

- 主标题是**你上传的文件名**，不是工作流名称；也没有网站图标。
- 数据是**整份替换**：重新上传或替换文件后，新文件有多少行就是多少行，不会和旧的拼在一起。
  （网页采集会在原有数据上累积，见下面「核心机制」。）
- **重复行原样保留**，不会去重。如果表里本来有一列叫 `id`，保存后会改名成 `file_id`。

详见[上传表格，按清单采集](/tutorial/upload-table)。
:::

### 卡片提供的快捷操作

- **点击主标题**：在新标签页唤出全屏表格预览视图。
- **「下载」按钮**：鼠标停上去提示「下载此数据集」，点开是格式菜单，支持导出 CSV、Excel、TXT、JSON、MD。详见[导出数据](/data/export)。
- **「上传飞书」按钮**：将本数据集一键推送写入飞书多维表格。详见[写入飞书多维表格](/data/feishu)。
- **刷新图标**（只有从文件导入的数据集才有）：悬停提示是「选择文件替换当前数据，保留数据集标识」。
  选一份新文件就能整份替换，替换成功会提示「文件数据已更新，原有工作流可继续使用」。
  工作流仍然指向同一个数据集标识，所以不用重新编译。
- **垃圾桶图标**：彻底删除该数据集及其本地存储的全部记录。删除操作不可撤回，重要数据请在删除前先行下载备份。

::: tip 下载与上传的权限
下载按数据集总条数和账号档位判断，非会员也可以下载符合免费额度的数据集；手动上传已有数据到飞书需要会员。具体见[导出数据](/data/export)和[写入飞书多维表格](/data/feishu)。
:::

## 全屏数据预览视图

点击卡片主标题，系统将在**独立的浏览器新标签页**中打开完整的数据网格。

![数据预览页左侧：顶栏显示数据集标识、共 299 行和更新时间，右边是「下载」「上传飞书」；表格从左往右依次是序号、排名、书名、热搜指数、作者、类型、简介](/images/preview-left.png)

![数据预览页把表格往右拖到底：最末尾是系统自动附带的「采集时间」和「数据来源页」两列，底部是每页行数选择和分页控件](/images/preview-right.png)

### 1. 顶栏操作区

- 左侧显示数据集标识、累计行数以及末次采集更新时间。
- 右侧常驻「下载」与「上传飞书」快捷操作，支持边核对边导出。

### 2. 字段排列与系统列

- **业务列**：显示工作流保存的字段（如标题、售价、销量），具体顺序以预览为准。
- **系统内置追踪列**：表格最末尾会自动附带两列系统字段，方便回溯源头：
  - **`采集时间`**：每条数据被抓取并写入本地的精确时间点。
  - **`数据来源页`**：该条数据采集自哪个具体 URL。在跨多页面或多详情页抓取时，能快速区分数据出处。

### 3. 在线快捷列类型切换

将鼠标悬停在任意列的表头上，点击弹出的类型按钮，可临时切换展示模式：

- **图片**：直接在单元格内渲染缩略图预览（抓取图片链接时极其实用，无需逐个点开链接核验）。
- **链接**：以可点击的超链接形式呈现。
- **文本**：以普通字符串形式呈现。

::: tip 渲染类型不改动底层数据
预览界面的类型切换纯粹为了方便视觉审阅，刷新页面后会重置，**不会改动已经存盘的数据原本格式，也不会影响最终导出的数据内容**。
:::

### 4. 极速分页加载

预览表格底部提供每页 **50 行** 或 **100 行** 的分页切换控件。数据量大时可通过分页逐页查看。

## 核心机制与疑难解答

### 1. 多次执行后，数据会越攒越多吗？

**会累积，但相同的内容不会重复存两份**。
同一个工作流每执行一次，系统都会把这次采到的每一条数据，和数据集里已有的数据逐条比对
（比的是你采集的那些字段内容，采集时间和来源页不参与比对）：

- **内容完全一样**：不再新增一行，只把这一行刷新成这次的采集时间和来源页。
- **内容不同，或是新出现的条目**：作为新行追加进来，原有数据继续保留。

所以每天跑一次的榜单类工作流，条数会随着新条目的出现增长；反复跑一份没有任何变化的页面，条数不会翻倍。

- 如果每次只想留一份干净的最新数据，执行前先在卡片上点垃圾桶删掉这个数据集
  （删除不可恢复，重要数据请先下载备份）。
- 如果希望在已有数据上做增量更新、只处理新条目，见[读取已有数据集](/data/read-dataset)。

### 2. 预览中发现个别列内容为空？

通常是因为网页未加载完毕即触发了提取，或者目标站点的某些条目本身缺省该字段。可参考[采不到数据怎么办](/troubleshooting/empty-result)在需求中适度添加等待时间。
