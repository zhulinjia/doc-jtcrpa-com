# 写入飞书多维表格

通过九头虫 Agent，你可以将采集到的数据**实时直连写入你自己的飞书多维表格**中，无需再手动下载文件再导入。

初次使用前需要做一次权限绑定。**虽然配置包含几个步骤，但只需操作一次，后续即可长期复用**。

## 两种使用模式对比

| 业务场景             | 触发方式                                                           | 是否需要会员         |
| :------------------- | :----------------------------------------------------------------- | :------------------- |
| **实时流式写入**     | 在采集需求中明确说明（如“采完直接写进飞书”），任务运行期间逐条写入 | **免费（无需会员）** |
| **历史数据事后上传** | 在「数据存储」卡片上手动点击「上传飞书」将已有结果全量推送         | **需要会员**         |

两类场景**共用同一套飞书配置**，只需完成一次配置即可支持全部模式。

::: tip 反过来，也能把飞书表当输入
采集之前先要读一张飞书多维表格里的数据？那是另一条路，但**用的是同一套配置**——
配好这篇的应用凭据后，直接在需求里给出表格链接就行，见[读取飞书多维表格](/data/feishu-read)。
:::

## 配置流程：两阶段 6 步法

::: tip 进入配置入口
点击侧边栏底部「**设置菜单**」→ 点击「**飞书多维表格**」。系统将在浏览器新标签页中打开配置页面。
:::

配置页面核心分为两阶段：**第 1~5 步为全局配置（只需做一次）；第 6 步为单表授权（每张要写入的目标表做一次）**。

### 阶段一：建立应用凭据（只需配置一次）

点击页面上的「**打开飞书开放平台**」按钮：

1. **创建企业自建应用**：登录飞书开放平台，点击「创建自建应用」，填写应用名称与图标。
2. **获取 App 凭据**：进入应用的「凭证与基础信息」页面，复制出 **App ID** 和 **App Secret**。
3. **开启多维表格权限**：进入应用的「权限管理」，搜索并开通「多维表格」相关的读取与写入权限。
4. **⚠️ 发布应用版本（最关键）**：进入「版本管理与发布」，创建一个新版本并申请发布。  
   _注意：如果未发布新版本，前面开通的权限完全不会生效！_
5. **回填凭证并测试**：返回扩展配置页，将 App ID 与 App Secret 分别填入输入框。

### 阶段二：授权具体表格（每张要写入的表做一次）

6. **添加文档应用**：在飞书浏览器中打开你要写入的多维表格，点击右上角「**···**」→「**··· 更多**」→「**添加文档应用**」，搜索并选中你在第 1 步创建的应用名称并确认授权。

## 凭据输入与连通性验证

扩展配置页包含三个输入项：

| 输入项                         | 填写规范                                                                                                                                     |
| :----------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **App ID**                     | 填入以 `cli_` 开头的应用标识字符串。                                                                                                         |
| **App Secret**                 | 填入应用密钥（创建时完整展示，请妥善保管）。                                                                                                 |
| **多维表格链接（仅用于测试）** | 打开你第 6 步授权好的那张多维表格，从浏览器地址栏完整复制 URL 贴入。该链接**仅用于校验本次接口连通性**，后续具体写入哪张表由工作流逻辑决定。 |

::: tip 页面自动保存
该页面没有独立的「保存」按钮，各项凭据**边填边存**，填好后点击「**测试连接**」按钮验证即可。
:::

## 常见报错与排错清单

若点击「测试连接」未通过，可根据提示对照下表解决：

| 错误提示                         | 根本原因                                 | 对应解决办法                                                           |
| :------------------------------- | :--------------------------------------- | :--------------------------------------------------------------------- |
| **这个链接里读不出表格标识**     | 复制的网址格式不完整或缺漏参数           | 在飞书打开该表，重新从地址栏复制一次完整 URL                           |
| **这是知识库里的表格，暂不支持** | 属于飞书知识库节点，无法直接读取底层标识 | 在右上角「···」→「··· 更多」中点击「在浏览器中打开」，复制新标签页网址 |
| **App ID 或 App Secret 不对**    | 凭证抄错或密钥已被重置                   | 返回飞书开放平台「凭证与基础信息」核对原样凭据                         |
| **这个应用还没被允许访问这张表** | 漏掉了第 6 步单表授权                    | 在该表格右上角点击「···」→「添加文档应用」加入自建应用                 |
| **应用缺少多维表格权限**         | 权限未开通或开通后未发布版本             | 确认开通多维表格权限，并在「版本管理」**发布一个正式版本**             |
| **请求太频繁，被飞书限流**       | 短时间内高频测试触发接口频率限制         | 稍等 1~2 分钟后再试                                                    |
| **这张表的记录数已达上限**       | 飞书该表格已达到单表行数配额             | 在飞书中清理冗余行，或指定一张全新的多维表格                           |

## 写入规则与数据约束

- **分批推送**：由于飞书单次写入上限，扩展每批次最多提交 500 条数据，超量数据会自动分批推送，期间请保持网络稳定。
- **列自动适配**：如果写入的字段在飞书表格中不存在，扩展会**自动在该表末尾新建一列文本字段**。若希望使用特定类型（如数字、日期），建议先在飞书表中提前建好对应列。
- **单选与多选列**：如果目标列是单选或多选类型，需提前在飞书表中把候选选项创建好，否则无法成功填入。
- **暂不支持的特殊字段**：附件、人员、关联双向记录、地理位置字段不支持直接通过自动化写入。
- **字段对应原则**：写入时按数据的列名与飞书列名对应，不会在写入时自动按语义匹配。需要不同名称时，在需求里明确说清楚，例如：`写入飞书时把商品标题命名为“商品名称”，价格命名为“现价”`。先用少量数据测试，确认没有意外创建新列。

::: warning 中断后重新发送可能产生重复记录
飞书写入按批次发送。若中途失败，前面已送出的记录不会自动撤销；恢复或重新上传可能再次发送这些记录。重试前先到飞书核对已收到的数据。
:::

::: warning 安全与隐私说明
App Secret 可用于访问你授权给该应用的表格。扩展的飞书配置保存在本机，不会作为飞书配置自动写进工作流导出文件。请不要将密钥直接写进采集需求或工作流步骤；分享工作流和日志前也应检查是否包含敏感信息。
:::
