# 导出数据

采集完成后，你可以随时将保存在本地的数据集导出为本地文件。

## 两个导出入口

两个入口导出的是同一份全量数据，按你的操作习惯选择即可：

- **入口一（在「数据存储」列表页）**：找到对应数据集的卡片，点击卡片右下角的**「下载」**按钮。
- **入口二（在数据预览大页）**：点击卡片大标题进入数据预览新标签页后，点击页面右上角的**「下载」**按钮。

点击后会展开格式选择菜单，点击对应格式即可触发浏览器原生下载，文件将保存至你的系统默认下载文件夹。

## 五种导出格式对照

| 格式名称          | 适用场景与优势                                                                                        |
| :---------------- | :---------------------------------------------------------------------------------------------------- |
| **CSV**           | **最通用（首选推荐）**。兼容各类表格工具（Excel、WPS、Numbers），也方便直接导入各类数据库或业务系统。 |
| **Excel (.xlsx)** | **直接交付**。适合需要直接发送给同事或客户开箱即用，或者需要立即在表格内编写函数公式。                |
| **TXT**           | **纯文本管道**。以制表符（Tab）分隔每列，适合作为后续 Python 脚本或自动化工具处理的数据源。           |
| **JSON**          | **开发者首选**。保留原始数据结构，不做任何字符截断或清洗，字段完整性最高。                            |
| **MD**            | **Markdown 格式**。生成标准的 Markdown 表格文本，便于直接复制并粘贴进飞书文档、Notion 或各类工单。    |

## 导出条数限制与额度说明

导出操作受账号当前的档位额度控制：

| 账号档位        | 单个数据集导出上限 |
| :-------------- | :----------------- |
| **非会员**      | 500 条             |
| **VIP1**        | 5,000 条           |
| **VIP2**        | 50,000 条          |
| **VIP3 及以上** | 不限条数           |

::: warning ⚠️ 超限是以「数据集总条数」判定的
当数据集条数超过档位上限时，**系统不会截断前 500 条给你，而是整个数据集均无法下载**，界面会明确提示：

> 本次 N 条超出当前档位上限（N 条），升级会员可提高额度

**非会员免费避坑技巧**：

- 如果仅是轻量试用，在编写采集需求时直接约定上限，例如：`最多采集 400 条`。
- 如果一次性任务过大，可以分批建多个工作流采集，保持单次在 500 条以内即可免费导出。

:::

## 常见导出问题排查

### 1. 用 Excel 打开 CSV 文件出现乱码？

正常情况下扩展已针对中文编码做了适配，如果个别旧版本 Excel 出现乱码，按以下方式解决：

- **方案 A（最简单）**：直接改选 **Excel 格式**重新下载导出。
- **方案 B**：新建一个空白 Excel，点击顶部菜单「数据」→「来自文本/CSV」，在编码选项中选择 **UTF-8** 导入即可。

### 2. 导出的长文本单元格被截断了？

- **原因**：Excel 等表格软件对单个单元格字符数有硬性限制（通常为 32,767 字符），为保证文件能被正常打开，超长正文（如长篇文章、长 HTML 代码）会被安全截断并附带标记。
- **对策**：如果需要抓取完整的超长正文，请使用 **JSON 格式**导出，JSON 格式不会对任何字段进行截断。
