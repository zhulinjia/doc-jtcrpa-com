# 导出数据

想在 Excel 或 WPS 中继续处理，先到「**数据存储**」找到结果，点击「**下载**」，选择 **Excel**。也可以在预览页右上角下载。

## 下载前先确认是哪份表

两个入口下载的是该数据集的完整内容，不是只下载预览当前这一页。历史记录也在里面时，会一起导出。想单独保存本次结果，先让原任务将结果写成一张新表，再运行并下载，见[数据存储](/data/storage-preview)。

## 按用途选择格式

| 格式 | 适合什么用途 |
| --- | --- |
| Excel | 用 Excel、WPS 打开，继续整理或交给同事 |
| CSV | 导入另一个支持 CSV 的表格或业务系统 |
| TXT | 需要纯文本内容 |
| JSON | 需要保存完整超长正文，或接收系统明确要求此格式 |
| MD | 需要把表格文本粘贴到支持 Markdown 的文档中 |

下载由浏览器处理，可以从浏览器下载记录找到文件。下载后打开核对表头、条数和几行实际内容。

## 下载条件与大文件

当前扩展按整份数据集的总条数判断下载权限：非会员 500 条、VIP1 5,000 条、VIP2 50,000 条、VIP3 及以上不限制条数。以界面针对当前账号的提示为准。超过限制时，不会只截取允许的前几条给你。

数据超过 10,000 行时会拆成多份文件下载。检查浏览器是否允许这次多文件下载，以及各份文件是否都已保存。

## 文件内容看起来不对

- **CSV 中文乱码**：优先改选 Excel 重新下载；也可在表格软件中按 UTF-8 导入 CSV。
- **号码前导零消失**：检查原结果是否保留了零，以及表格软件是否把该列当成数字。可以让 AI 按文字保留号码，重新采集并检查。
- **超长内容被截断**：Excel、CSV、TXT、MD 对过长单元格有处理限制；需要完整超长正文时选择 JSON，并核对下载内容。

结果怎么保存和分享，接着看[备份、迁移与分享工作流](/advanced/import-export)。
