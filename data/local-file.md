# 读取本地文件

先按你希望文件怎样更新，选择用法。

| 你的需要 | 推荐方式 |
| --- | --- |
| 先拿一份 Excel 或 CSV 清单练习 | 在对话中「添加文件」，见[上传表格，按清单采集](/tutorial/upload-table) |
| 磁盘上的文件经常更新，任务每次要重新读取 | 让工作流运行时读取本地文件 |

## 添加文件：更适合第一次使用

在「**AI 编译生成**」点击「**添加文件**」，支持 Excel、CSV、JSON、TXT。根据页面提示确认首行是否作为列名，再说要用哪一列、整理什么内容。

文件会在本机保存一份快照。磁盘原文件之后改变，不会自动改变这份快照。可在「数据存储」的文件卡片上选择新文件替换，保留原来的引用。文件本身的重复行会保留。

在「**主工作台**」，引用已上传文件的工作流卡片上可以点「**输入文件**」。点「**查看数据**」核对当前内容，或点「**更新文件**」并选择新版清单。看到「文件数据已更新」后，引用同一份文件的工作流就会使用新版数据。

## 每次运行都读磁盘文件

这种方式目前需要 Chrome / Edge 的相关文件访问能力。Firefox 用户可以改用上面的添加文件方式。

向 AI 说明要读取的文件及用途；遇到文件访问提示卡片时，按卡片指引完成准备。Chrome / Edge 可能需要到该扩展的详情页开启「**允许访问文件网址**」。

运行时直接读到的内容用于这次任务，不一定单独出现在「数据存储」。需要保留处理结果时，再说明要保存成表格。文件移动、改名或换电脑后，原路径也需要重新核对。

## 读不出来时

先用 Excel 或 WPS 打开文件，确认文件本身能正常读取。CSV 出现乱码时，可另存为 CSV（UTF-8）后重试；表头、网址列没识别对时，把实际列名告诉 AI。复杂表格先保留几行，确认读取和处理都正确再使用完整文件。
