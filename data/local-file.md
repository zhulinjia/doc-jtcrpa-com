# 读取本地文件

如果文件一直放在电脑上，或者你希望每次运行都读取**最新版本**的文件，可以直接在采集需求里
给出文件的完整路径。扩展会在运行时去读那个文件，不把它复制进「数据存储」。

::: warning 目前只支持 Chrome / Edge
Firefox 读不到本地文件，提示会是「当前浏览器不支持读取本地文件」。
在 Firefox 里请改用[上传表格，按清单采集](/tutorial/upload-table)。
:::

## 一、在需求里写完整路径

直接告诉 AI 文件在哪，例如：

> 读取本地文件 `D:\资料\商品清单.xlsx`，打开里面每个商品链接，采集标题和价格。

> 读取 `/Users/你的用户名/Desktop/订单.csv`，统计每个城市的订单数。

规则只有一条：**必须是完整的绝对路径，并且写到具体文件。**

| 系统          | 正确写法                          | 不能这样写                                   |
| :------------ | :-------------------------------- | :------------------------------------------- |
| Windows       | `D:\资料\清单.xlsx`               | `清单.xlsx`（相对路径）、`D:\资料`（文件夹） |
| macOS / Linux | `/Users/me/Desktop/清单.csv`      | `~/清单.csv`、`./清单.csv`                   |

路径会原样写进工作流。文件换了位置、改了名字，要回对话里把新路径告诉 AI。

## 二、第一次用：开「允许访问文件网址」

第一次读取时，对话里会出现一张卡片，标题是「**需要开启「允许访问文件网址」**」。照着卡片走：

1. 点「**去开启权限**」——打开本扩展在浏览器里的详情页。
2. 找到「**允许访问文件网址**」，把它打开。
3. 回到侧边栏，点「**已开启**」。

::: tip 浏览器里它叫「九头虫 Agent」
扩展详情页上的名字是「**九头虫 Agent**」——**就是它**，别找错了。
:::

开好后，扩展会替你发一句「已开启本地文件读取权限，继续」，卡片收成「**已开启，继续执行**」。

### 卡片点了没反应？

| 卡片上出现这句                                                               | 什么意思                             | 怎么办                                                   |
| :--------------------------------------------------------------------------- | :----------------------------------- | :------------------------------------------------------- |
| **浏览器不让扩展自己打开这个页面，请手动打开 chrome://extensions 找到本扩展** | 浏览器不允许扩展自己跳转             | 自己在地址栏打开扩展管理页，找到「九头虫 Agent」，一样能开开关 |
| **还没检测到「允许访问文件网址」，确认开关已打开再点一次**                   | 开关其实还没开上                     | 确认开关真的打开了，再点一次「已开启」                   |
| **这个版本的扩展还没有读取本地文件的权限，更新后再试**                       | **不是浏览器开关的事**，是版本问题   | 更新或重新安装扩展。这种情况卡片只有步骤，没有「去开启权限」按钮 |

## 三、运行时会发生什么

- **支持的文件**：Excel（`.xlsx` / `.xls`）、CSV、JSON、TXT。
- **只读第一个工作表**：Excel 文件里有多个工作表时，只读第一个，不会自动合并。
- **有多少行读多少行**，不设行数上限；空文件读成 0 行。
- **结果只进入这次工作流，不会出现在「数据存储」**。要留存一份，请用[上传表格，按清单采集](/tutorial/upload-table)。
- **每次运行都重新读磁盘上的文件**：你改了文件，下次运行读到的就是新内容，不用重新编译。
- 执行日志会写读取结果：

  > 已读取本地文件「D:\资料\清单.xlsx」工作表「Sheet1」：120 行

  CSV / TXT / JSON 没有工作表，日志里不写工作表名：

  > 已读取本地文件「D:\资料\清单.csv」：120 行

### 第一行是不是列名，不用你判断

AI 会先尝试判断文件结构，判断仍可能出错。建议在需求里明确加一句
「第一行是表头」或「第一行不是表头，也是数据」。

## 四、报错怎么查

日志里的原话和对应处理：

| 日志里的原话                                                                                                                     | 原因                                   | 怎么办                                             |
| :------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------- | :------------------------------------------------- |
| 「读取本地文件失败：路径不是有效的绝对路径…」                                                                                     | 写成了相对路径，或只写到文件夹         | 换成完整路径，写到具体文件                         |
| 「读取本地文件失败：扩展没有读取本地文件的权限…」                                                                                 | 「允许访问文件网址」没开               | 回到[第二节](#二-第一次用开-允许访问文件网址)开权限 |
| 「读取本地文件失败：文件不存在、被占用或无法访问」                                                                               | 文件被挪走、删掉，或正被别的程序占用   | 确认路径和文件状态，关掉占用它的软件再跑           |
| 「读取本地文件失败：不支持的文件格式，只支持 .txt / .json / .csv / .xlsx / .xls」                                                | 文件类型不支持                         | 另存为支持的格式                                   |
| 「读取本地文件失败：无法识别文件编码（不是 UTF-8、GBK/ANSI 或带 BOM 的 UTF-16）」                                                | 文件编码太特殊                         | 用表格软件另存为 CSV（UTF-8）                      |
| 「读取本地文件失败：文件不是合法的 JSON，无法解析」                                                                               | JSON 内容有语法错误                    | 检查 JSON，或改成 CSV                              |
| 「读取本地文件失败：Excel / CSV 文件解析失败，文件可能已损坏或不是声明的格式」                                                    | 文件损坏，或扩展名和实际内容对不上     | 用 Excel 打开确认，再另存一份                      |
| 「当前浏览器不支持读取本地文件，请改用其他方式获取数据」                                                                         | 用的是 Firefox                         | 改用[上传表格](/tutorial/upload-table)             |

## 五、和「上传表格」怎么选

|                    | 上传表格                                   | 读取本地文件                             |
| :----------------- | :----------------------------------------- | :------------------------------------------- |
| 文件放在哪         | 浏览器里保存一份快照                       | 每次运行都读磁盘上的原文件                   |
| 需要额外开权限     | 不需要                                     | Chrome / Edge 要开「允许访问文件网址」        |
| 换文件内容         | 到「数据存储」点刷新图标替换               | 直接改磁盘上的文件，下次运行生效             |
| 数据会不会留在本地 | 会，出现在「数据存储」里                   | 不会，只供这次工作流使用                     |
| Firefox            | 支持                                       | 不支持                                       |
