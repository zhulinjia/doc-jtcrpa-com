# 上传表格，按清单采集

如果你已经有一份网址清单，可以交给 AI，让工作流逐个打开网页、采集需要的内容。

下面用两本书的网址练习：上传清单，采集每本书的书名和价格，再核对结果。

## 1. 下载练习表格

<a href="/examples/books-links.csv" download>下载书籍网址清单</a>，并记住文件保存的位置。

这份表格只有一列「网址」，里面有两本书的详情页地址。你可以用表格软件打开查看，也可以直接用于下面的练习。

## 2. 上传表格并发送需求

1. 在浏览器中打开[书籍练习网站](https://books.toscrape.com/)，停留在这个页面。
2. 点击浏览器工具栏上的九头虫图标，进入「**AI 编译生成**」。
3. 点击输入框下方的回形针按钮「**添加文件**」，选择刚下载的书籍网址清单。
4. 等文件处理完成，检查文件卡片是否显示 **CSV · 共 2 行**和列名「**网址**」，并保持「**首行作为列名**」勾选。
5. 在输入框中复制并发送下面的需求：

> 请逐条打开上传表格中「网址」列的网页，采集每本书的书名和价格，直接保存到同一份数据集中，不使用自定义脚本。

发送后，等待 AI 分析编译。如果 AI 提出问题，请根据练习要求回答。编译完成后，工作流会保存在「主工作台」。

## 3. 启动采集

回到[书籍练习网站](https://books.toscrape.com/)，打开侧边栏的「**主工作台**」，找到刚生成的工作流，点击「**手动启动**」。运行期间请不要操作网页或最小化浏览器。

## 4. 查看结果

运行结束后，打开「**数据存储**」。上传的清单和采集结果是两份数据：文件名为 **books-links.csv** 的是清单。找到另一份采集结果，点击标题打开预览，检查书名和价格。

在预览中向右查看「**数据来源页**」列，可以看到每条数据来自哪个网址。把它和清单里的网址对照，检查是否对应。

目前这两本书的内容如下，网站内容可能变化，请以网页实际显示为准：

| 书名 | 价格 |
| --- | --- |
| A Light in the Attic | £51.77 |
| Tipping the Velvet | £53.74 |

检查无误后，可以在采集结果的数据集卡片上点击「**下载此数据集**」，选择 Excel 或 CSV 保存。

## 换成自己的清单

练习通过后，可以上传自己的 Excel、CSV、JSON 或 TXT 文件。在需求中说清楚**哪一列是网址、要采集哪些内容**。如果只想先试几条，也可以写「只处理前 3 条」。

文件在浏览器本地解析和保存；AI 会看到列名、行数和少量样例。选中文件后还需要和需求一起发送，文件才会保存到「数据存储」。

如果想用新文件替换已上传的清单，又让原工作流继续使用，可以在「数据存储」找到该文件，点击卡片上的刷新图标，选择新文件。替换会覆盖原清单，请在任务结束后操作。

## 遇到问题

- **文件卡片上的列名不对**：检查「首行作为列名」是否勾选，以及第一行是否确实是列名。
- **没有采集结果或内容不对应**：打开工作流卡片上的「**查看运行日志**」检查提示；也可以在[修改已有工作流](/guide/modify-workflow)中说明哪条数据不对，再试一次。
- **网址打不开**：先手动打开清单中的网址，确认网页能正常访问；需要登录的网站请先在浏览器登录。

::: details 更多关于上传文件的说明

- 可以一次添加多个文件，每个文件会单独显示一张卡片。发送之前可以移除；发送之后移除对话中的附件，不会删除「数据存储」里的文件数据。
- 文件里的重复行会保留。如果原表有一列叫 `id`，保存后会显示为 `file_id`，以免与系统列重名。
- 替换清单后，原工作流会使用新内容。请在任务结束后再替换，以免影响正在进行的采集。
- 如果文件无法解析，可以用表格软件打开后另存为 CSV（UTF-8），再重新添加。

:::

如果你想读取电脑上的文件而不是上传到对话，请看[读取本地文件](/data/local-file)。
