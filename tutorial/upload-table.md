# 上传表格，按清单采集

手上已经有一份表格——比如商品链接清单、待核对的名单、订单号列表——可以直接交给 AI。
它会先读懂这份表里有哪些列，再按你说的方式处理每一行，不用你逐条复制粘贴。

::: tip 支持的文件
Excel（`.xlsx` / `.xls`）、CSV、JSON、TXT。文件只在你的浏览器本地解析和保存，
完整内容不会上传给 AI；AI 看到的是列名、行数和少量样例。
:::

## 一、把文件交给 AI

1. **先停在一个普通网页上。** 当前标签页不要是浏览器设置页、扩展商店页或扩展自己的页面，
   否则消息发不出去。
2. **点输入框下方的回形针按钮**（鼠标悬停显示「添加文件」），选中文件；
   也可以直接把文件拖进输入框。
3. **核对出现的文件卡片**：
   - 第一行是文件名；解析时显示「文件处理中…」。
   - 下面是格式和行数，例如「CSV · 共 120 行」。
   - Excel / CSV 会多一个「**首行作为列名**」勾选项。勾着表示第一行是表头；
     如果你的第一行本身就是数据，取消勾选。
   - 再下面是识别出的列名，用「 · 」隔开。
   - 解析失败时，卡片上会直接写原因；点右侧的「×」（移除文件）可以换一个。
4. **在输入框里写需求，然后发送。** 一次可以选多个文件，每个文件单独一张卡片。

::: tip 选文件不会自动发送
文件只是先放进输入框。你可以先把需求写完再一起发出去；发送之前随时可以移除。
:::

![输入框上方已选好文件：文件名、格式与行数、「首行作为列名」勾选项、识别出的列名](/images/upload-file-card.png)

卡片上的每个部分都能核对：第一行是文件名，第二行是格式和行数，
勾选「**首行作为列名**」表示第一行当表头用，最下面一行是识别出来的列名。
点卡片右上角的「×」可以把这个文件去掉。

## 二、怎么描述要它做什么

发送后，AI 会先看这份表的真实列名和少量样例，再决定怎么处理。你只要说清楚目标：

| 你想做的事           | 可以这样说                                       | AI 会怎么处理                         |
| :------------------- | :----------------------------------------------- | :------------------------------------ |
| 逐条打开清单里的链接 | `打开清单里每个商品链接，采集标题、价格和销量`     | 自动处理整份清单，一条一条打开采集    |
| 只处理前几条         | `只处理清单里的前 10 条`                         | 只处理前 10 条，后面的不动            |
| 筛选或统计           | `统计清单里每个城市的订单数`                     | 遍历整份表做计算，不会逐条打开链接    |
| 先看结构再决定       | `这份表里有哪些列？先给我看看前几行`             | 只回答结构，不生成采集流程            |

**不需要**告诉它一共多少行、每页多少条、要循环几次——这些由程序自己安排。
只有你**明确只要前 N 条**时，才需要加一句「只处理前 10 条」。

::: warning 要打开网页的那一步仍然需要网页
如果任务包含「打开链接采集」，运行期间请保持在目标网页所在的窗口，别最小化。
文件本身已经保存在本地，不会因为你关掉原来的文件而丢失。
:::

## 三、运行中会看到什么

处理清单时，执行日志会逐条显示进度，例如：

> 正在处理数据集「…」第 3 条（共 120 条）

最后一条处理完，会显示：

> 已遍历数据集「…」：120 条

日志里的「数据集「…」」显示的是卡片下方那行**系统标识**，不是文件名，对上就行。

## 四、上传后的数据在哪

发送成功后，这份文件会作为一份**数据集**出现在「数据存储」里：

- **卡片主标题**就是你上传的文件名（不是工作流名）。
- 点主标题可以打开全屏预览，逐行核对；也可以用「下载」导出。
- **同名文件不会互相覆盖**：每次上传都是新的一张卡片。

### 想更新文件内容，但让旧工作流继续用

1. 回到「数据存储」，找到这张卡片。
2. 点右下角那一排图标里的**刷新图标**（悬停提示「选择文件替换当前数据，保留数据集标识」）。
3. 选中新文件。替换成功后提示「**文件数据已更新，原有工作流可继续使用**」。

替换是**整份替换**：新文件有多少行就是多少行，不会把旧数据和新数据拼在一起。
工作流仍然指向同一个数据集标识，所以不用重新编译。

<!-- 依据：entrypoints/sidepanel/pages/storage/update-file-button.tsx；
     lib/db/dataset-db.ts 的 importFile 先清空 rows 再写入新快照。 -->

::: tip 在对话里移除附件 ≠ 删除数据
发送前移除，文件不会保存；发送后再移除对话里的卡片，**已保存的数据集不会跟着删除**。
要删数据，请到「数据存储」点垃圾桶。
:::

## 五、常见问题

| 遇到的提示                                                         | 原因                                   | 怎么办                                     |
| :----------------------------------------------------------------- | :------------------------------------- | :----------------------------------------- |
| 「仅支持 Excel、CSV、JSON 和 TXT 文件」                            | 选了不支持的文件类型                   | 另存为这几种格式再选                       |
| 「无法识别文件编码（不是 UTF-8、GBK/ANSI 或带 BOM 的 UTF-16）」    | 文件编码不是常见的中文/英文编码        | 用表格软件另存为 CSV（UTF-8）再选          |
| 「文件不是有效的 JSON，请检查后重试」                              | JSON 内容有语法错误                    | 用能打开 JSON 的工具检查，或改成 CSV       |
| 「文件解析失败，请检查文件内容」                                   | Excel / CSV 损坏，或与扩展名不符       | 用 Excel 打开确认能正常显示，再另存一份    |
| 「数据保存失败，请重试」                                           | 本地存储写入失败                       | 稍后重试；反复出现请把日志发给我们         |
| 运行中提示「数据集「…」在运行中已更新，请结束本次运行后重新运行」   | 任务运行期间替换了这个文件             | 等这次跑完，再重新运行                     |

::: tip 两件容易误会的事

- **重复行会保留**：文件里的重复记录会原样保留，不会被去重；导出的条数和原文件一致。
  （这和网页采集的「自动去重」不同。）
- **`id` 列会自动改名**：如果表里本来就有一列叫 `id`，保存时会改成 `file_id`，
  以免和系统自己的列冲突；预览里看到的列名以改写后的为准。AI 知道这件事，按原名说需求即可。

:::
