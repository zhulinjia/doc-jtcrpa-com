# 表单录入与提交

有些页面的数据，得先把表单填好才会出现：搜索框、筛选下拉、勾选项、日期区间，
甚至是要逐条提交的查询表单。这些「填什么、点哪儿」同样可以交给 AI，
填完之后再接着采集。

::: warning 开始前

1. 先在浏览器里登录目标网站。
2. 打开并停留在**含有这张表单**的页面。
3. 填写会真的生效——按回车、点按钮都可能**真的提交**。第一次试建议先用一张无关紧要的表单，
   或者在需求里加一句「先不要点提交」。

:::

## 操作步骤

### 1. 输入采集需求

**打开目标网页 -> 点击右上角九头虫图标打开侧边栏 -> 切到「AI 编译生成」-> 在对话输入框里写下需求。**

例如：

> 在当前页面的搜索框里输入「机械键盘」，把排序下拉选成「销量」，勾上「只看有货」，
> 点「搜索」；然后等结果列表出来，采集前 2 页的标题、价格和销量。

<!-- TODO: [截图] 需求里同时包含填表与采集的状态 -->

### 2. 等待编译完成

AI 会逐个找到输入框、下拉框、复选框和按钮，试填一遍。编译完成后工作流自动保存，
在「主工作台」里出现。

### 3. 执行并导出数据

回到「主工作台」，点工作流卡片上的 **「手动启动」**。运行期间它会自己填、自己点，
**这个页面你不要动**。跑完切到「数据存储」核对结果、下载数据，步骤同
[列表与翻页采集](/tutorial/list-pagination)。

::: tip 流程还没确认？先别让它提交
可以第一遍只说填表和筛选，不加「点提交」。看过填进去的内容没问题，再回对话里补一句
「可以点提交了」，AI 会在原来的基础上把提交那一步加上。
:::

## 它能填哪些表单项

| 表单项                        | 它会怎么做                                       | 需求里可以这样说                                       |
| :---------------------------- | :----------------------------------------------- | :----------------------------------------------------- |
| 单行输入框、多行文本框、富文本 | 把文字填进去。默认**逐字输入**，能触发网站的下拉联想 | `在搜索框输入「机械键盘」`                             |
| 输入后的结尾按键              | 想按回车、换行或跳到下一项就明说；**不说就只填不按** | `输入完按回车搜索`、`在留言框里按 Shift+回车换行`、`填完按 Tab 跳到下一项` |
| 下拉框                        | 原生下拉和网站自己画的下拉都行，按选项**看得见的文字**选中 | `把城市选成北京`、`排序方式设为最新`                   |
| 复选框、单选框                | 把它**设成**选中或取消选中；已经是那个状态就不会再动 | `勾选同意协议`、`取消全选`、`把「男」选上`             |
| 按钮、链接                    | 点一下                                           | `点「搜索」`、`点下一步`                               |

::: tip 说「状态」，不用说「点一下」
复选和单选直接说要它处于哪种状态就行（「勾上」「取消勾选」），重复执行也不会被点反，
跑一半中断后重新跑也安全。
:::

## 提交之后：等结果出来再采

表单提交后页面通常会刷新，或者列表重新加载。这时候马上采集很容易采空，
在需求里接一句等待：

> ……点「搜索」；**等结果列表加载出来**再采集前 2 页的商品标题和价格。

比写死「等待 3 秒」更稳，见[等页面加载完成再采集](/tutorial/wait-page)。

## 按清单逐条填

要按一份清单一条条填（比如逐个商品查价、逐条提交查询），不用告诉它循环几次：
把清单文件直接传进对话，说清楚「清单里每一条都按这个表单查一次」，
见[上传表格，按清单采集](/tutorial/upload-table)。

## 容易出问题的地方

| 遇到的提示 / 现象                          | 原因                                           | 怎么办                                                       |
| :----------------------------------------- | :--------------------------------------------- | :----------------------------------------------------------- |
| 「下拉框里没有匹配「…」的选项；可选：…」    | 选项文字和页面上的对不上                       | 照它列出的可选值改需求里的写法                               |
| 点了按钮页面没反应，后面采到的全是空       | 表单校验没过（必填项没填、格式不对、协议没勾） | 先手动填一遍，看清页面提示缺什么，再把它补进需求             |
| 选完下拉，页面自己整页刷新了一下 | 有些网站的筛选一改就整页重载，打断了正在跑的步骤 | 等一会儿它可能自己接上；一直不动就在卡片上点「恢复」；反复出现就在需求里写「选完等列表出来再采」 |
| 勾选框怎么都勾不上                         | 那不是真正的复选框，而是网站自己画的「选项卡片」 | 把说法改成「点击某某选项」再试                               |
| 找不到输入框 / 按钮                        | 弹窗还没打开、页面改版了                       | 先手动把弹窗点开，再让 AI 重新描述一遍                       |
| 出现验证码                                 | 网站要你本人证明身份                           | 你手动过一下，运行会等你，见[登录、验证码与人工介入](/tutorial/login-captcha) |

::: warning 会真的提交、下单、发布
「提交」「下单」「发布」「删除」「注销」这类按钮点下去就生效，不会回头。
先确认好要它填什么、点什么，再让它点；带钱的操作尤其别让 AI 自己拿主意。
:::
