# 把结果发送给其他系统

有些系统提供一个接收地址，可以让工作流把数据发过去。这类功能通常需要接收方提供资料；新手可以先用下面的一条虚构订单练习。

## 1. 打开练习，发送需求

<PracticeTask lesson="send" />

这个地址是第三方测试服务，会返回收到的内容。只发送练习页的虚构订单；不要向它发送个人信息、密码或真实业务数据。测试服务不可用时，先停止练习。

## 2. 运行并检查返回内容

等 AI 准备好后，保持练习页在当前标签页，在「**主工作台**」点击新工作流的「**手动启动**」。

然后到「**数据存储 → 预览**」检查返回结果，应该包含 **DD5001 / 山海之间 / 32**。只看到原订单，或只看到“工作流已完成”，还不能确认对方正确收到了数据。

没有返回结果时，点击工作流的「**日志**」，找到发送步骤，展开查看结果。请求超时后，先确认接收方是否已经收到，再决定是否重试，避免重复发送。

如果表格里出现一行空白值，从原工作流的「**修改**」进入，直接告诉 AI：“返回结果的订单编号、商品和金额都是空的，请帮我修正，并把这次的正确返回结果单独存成一张新表。”修正后仍要重新运行并核对，不能只看保存成功。

## 3. 换成自己的接收系统

向接收方索取接收地址、发送要求、需要的字段和身份验证方式，把对方提供的说明交给 AI。先发送一条测试记录，让对方确认字段和值正确后，再增加数量。

这类发送不会自动继承你在网页上的登录状态。如果对方只有网页登录入口，先问它是否提供这种接收方式。地址、验证信息与数据可能交给所选 AI 或接收系统，分享工作流和日志前先检查内容。
