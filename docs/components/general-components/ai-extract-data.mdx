# AI 智能采集

用自然语言描述你要提取什么数据，AI 自动解析页面结构并返回结构化结果。

---

## 配置说明

### 数据存储

填写变量名（如 `products_table`），提取结果存入该变量，下游通过 `{{变量名}}` 引用。

### 提取范围

限定 AI 从页面哪个区域提取。支持 CSS 选择器（如 `.product-list`）或语义描述（如"商品列表区域"）。限定范围能避免页面其他区域干扰。

### 采集提示词

用自然语言描述要提取哪些字段。例如：

```
提取商品列表的所有商品。字段包括：商品标题、折后价格、划线原价、总销量、主图 URL。
```

系统内置三个快捷模板，点击即可填入：

| 模板 | 提取字段 |
|------|---------|
| 🛍️ **电商商品** | 商品标题、折后价格、划线原价、总销量、主图URL |
| 💼 **招聘列表** | 招聘职位、薪资待遇、公司全称、学历要求、福利标签 |
| 💬 **评论舆情** | 用户名、评论内容、发布时间、互动数、IP属地、情感倾向 |

填入后可自行修改。

### 预览结果

点击提示词输入框右侧的 👁 按钮，在当前页面实时预览提取结果，确认无误后再运行流程。

## 参数参考

| 参数 | 说明 |
|------|------|
| 数据存储 | 必填。提取结果存入的变量名 |
| 提取范围 | 必填。CSS 选择器或语义描述，限定提取区域 |
| 采集提示词 | 必填。自然语言描述要提取的字段 |

## 常见问题

### 提取结果为空

- 确认「提取范围」正确命中了数据所在的容器元素
- 提示词尽量具体（如"折后价格"而非"价格"）
- 如果数据是异步加载的，在前面加「[等待元素](./wait-element)」确保内容渲染完毕

### 字段名或类型不符合预期

在提示词中明确指定字段名；提取后接「[设置变量](./set-variable)」配合[数据清理管道](/core-concepts/data-transform)转换类型。
