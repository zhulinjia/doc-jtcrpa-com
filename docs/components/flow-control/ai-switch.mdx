# AI 多路分支

AI 多路分支节点利用 AI 模型对输入内容进行语义理解，从多条自然语言描述的分支条件中自动选出最匹配的一条，将流程导向对应的输出端口。

与普通[多路分支](./multi-branch)不同：你不需要填写精确的匹配值，也不需要纠结"精确匹配还是包含匹配"——每条分支条件用大白话写就行，AI 会自己判断内容该走哪条路。

---

## 什么时候用

普通多路分支要求你事先知道变量可能的具体值（如 `status` 等于 `"已发货"`、`"待付款"`……）。但现实中很多分类场景无法用精确值穷举：

- 根据网页内容判断当前处于什么页面（商品页、列表页、购物车、结算页……）
- 将采集到的文本按业务类型分类（正常商品、广告推广、关联推荐……）
- 根据页面状态决定下一步操作（正常浏览、遇到弹窗、触发验证码、页面空白……）

这些场景中，分类依据是**语义**而不是精确值。AI 多路分支就是为这类场景设计的。

## 配置说明

### 待判定内容

输入需要 AI 分类的文本。通常是上游采集到的网页文本、API 响应或变量值。支持 `{{变量名}}` 引用。

### 分支规则 (Cases)

定义多条分支条件，每条用自然语言描述一个分类标准。点击「添加 Case」增加分支，每条分支对应面板上的一个输出端口。

例如，你正在抓取电商网站，想根据页面内容判断走到了哪种页面：

| 分支条件 |
|---------|
| 当前页面是商品详情页，包含商品标题、价格、规格等信息 |
| 当前页面是商品列表/搜索结果页，包含多个商品卡片 |
| 当前页面是购物车页面，包含结算按钮和商品清单 |
| 当前页面弹出了登录弹窗或验证码验证 |

> **注意**：Case 从上到下依次评估，一旦匹配就不再继续检查后面的 Case。把更精确、更具体的条件排在前面。

### Default 分支

如果待判定内容不满足**任何一条**已定义的 Case 条件，流程会走 Default 默认分支。Default 分支**始终存在**，不需要额外配置，但**必须连接**到下游节点——确保流程有兜底路径。

---

## 运行逻辑

节点执行时，按以下步骤处理：

1. 解析「待判定内容」中的变量引用
2. 将待判定内容和所有 Case 条件一起发送给 AI 模型
3. AI 逐一对比语义契合度，选出最匹配的那条 Case
4. 如果没有任何 Case 满足，返回 `"default"`
5. 流程走向匹配到的 Case 对应的输出端口（或 Default）

## 参数参考

| 参数 | 说明 |
|------|------|
| 待判定内容 | 必填。需要 AI 分类的文本内容，支持 `{{变量名}}` 引用 |
| 分支规则 (Cases) | 至少一条。用自然语言描述每条分支的匹配条件，支持动态增删 |

## 常见问题

### 和普通多路分支有什么区别？什么时候用哪个？

| | 普通多路分支 | AI 多路分支 |
|------|------------|-----------|
| 匹配方式 | 精确值或包含匹配 | AI 语义理解 |
| 条件写法 | 填写具体的匹配值（如 `"已发货"`） | 自然语言描述（如"页面显示已发货状态"） |
| 适用场景 | 变量值可枚举、确定性高 | 分类标准是语义层面、无法枚举具体值 |
| 速度 | 即时 | 需等待 AI 响应（稍慢） |
| 消耗 | 无 | 少量 AI token |

> **建议**：如果变量值是可枚举的确定性值，优先用普通多路分支。只有语义模糊、无法精确枚举的场景再用 AI 多路分支。

### 内容同时满足多个 Case 条件，会走哪条？

Case 从上到下依次评估，AI 会综合考虑"语义契合度最高"和"排序靠前"两个因素。换句话说：如果两条 Case 都匹配，AI 会选择更契合的那条；契合度相同时排在上面的优先。建议将更精确、更具体的条件排在前面。

### 判断不准怎么办？

- **条件写具体**：不要写"页面正常"，而是"页面完整加载，显示了商品列表或详情内容"；不要写"页面异常"，而是"页面弹出登录弹窗、滑块验证码或错误提示"
- **缩小内容范围**：不要直接给一整页 HTML，在上游用「[设置变量](../general-components/set-variable)」提取关键文本段落再传给 AI 判断
- **调整 Case 顺序**：把最容易混淆的条件区分开，用更具体的措辞重写

### 需要什么前置配置？

和 [AI 条件判断](./ai-condition) 一样，需要先在插件设置中完成 [AI 模型配置](../../reference/ai-config)（API Key、模型选择等）。未配置时配置面板会提示完成 AI 设置。
